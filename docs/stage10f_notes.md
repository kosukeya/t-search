# Stage 10F Notes — Ablation / Wrong-Typing / False-Positive Controls

Status: **Stage 10F completed; criteria 44–47 satisfied.**

## Purpose

Stage 10A–10E established a fully typed finite future-measurement family. Stage 10F asks whether that positive result could be reproduced by retaining only convenient matrices/numbers while dropping the semantic resources that identify the same operational question across perspectives.

The central distinction is:

`numerical reconstructibility != typed operational identification`.

The Stage 10F status vocabulary remains functional rather than metaphysical:

`preserved / reconstructible / inaccessible / lost / underdetermined / not_established`.

Overall measurement covariance may additionally be classified as:

`established / partial / refuted / not_established`.

## Correspondence ablations

Three ablations remove one correspondence resource while leaving the stored measurement matrices untouched:

1. event correspondence removed;
2. continuation-class correspondence removed;
3. outcome correspondence removed.

In all three cases the numerical payload remains `preserved`, but the corresponding cross-perspective typed identification is `lost`. Because the same operational question can no longer be licensed from the retained typing alone, fully typed probability covariance is classified `not_established` rather than inferred from unchanged numbers.

This is an intentional false-positive control:

`same numeric probability + missing correspondence != validated measurement covariance`.

## Normalization ablations

Stage 10F distinguishes two different failures.

### Missing normalization semantics

If the normalization matrix remains available but its Stage 10 operational Born-rule role is no longer typed:

- numerical normalization payload: `reconstructible`;
- typed normalization identity: `underdetermined`;
- probability covariance: `not_established`.

The matrix alone does not specify why it is the correct denominator for the declared measurement family.

### Fresh numerical identity

If a non-Euclidean-unitary chart replaces the retained transported normalization with a fresh numerical identity, a tomography-complete Stage 10D probe family exposes nonzero probability residuals above tolerance.

This corrupted rule is therefore `refuted`, not merely untyped.

`missing semantics != false rule`.

## Required false-positive witnesses

Stage 10F provides executable witnesses for the frozen controls:

- **bare-effect reuse**: source-chart effects differ from the correctly represented target-chart effects by a nonzero matrix residual;
- **wrong continuation**: h_L/h_R chart forms differ and cross-use is rejected by continuation typing;
- **wrong outcome**: the canonical future-signature outcomes are operationally discriminating, while swapped outcome correspondence fails the semantic audit;
- **wrong event**: the misdeclared-preserving event correspondence fails the event-role audit;
- **weight misalignment**: swapping `(0.75,0.25)` to `(0.25,0.75)` while keeping the continuation likelihood rows fixed changes the weighted future prediction;
- **fresh-identity / mixed normalization**: substituting numerical identity for the transported normalization produces a nonzero tomography-family probability residual.

The executable diagnostics retain each residual explicitly rather than relying on prose-only rejection.

## What survives the ablations

A useful Stage 10F pattern is that several numerical objects remain available even after semantic identification is lost. This strengthens, rather than weakens, the reason for explicit typing:

- retained matrices do not by themselves identify event roles;
- retained matrices do not identify continuation classes;
- retained outcome-labelled numbers do not license cross-chart outcome identity without correspondence;
- a retained normalization form does not by itself specify its operational semantics.

Therefore:

`reconstructible != universally redundant`.

`preserved numerical payload != preserved typed role`.
