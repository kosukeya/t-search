# Stage 11F Notes — Ablation / Wrong-Gauge / False-Positive Controls

Stage 11F closes criteria **44–47** by pressure-testing the positive Stage 11A–E construction rather than adding a new physical model.

Central distinction:

`numerical reconstructibility != typed operational identification`.

Additional guards:

- `reconstructible != universally redundant`;
- `lost != metaphysically irreducible`;
- `missing typing != metaphysical absence`;
- `wrong-gauge failure != ontological becoming`;
- `finite-model ablation != fundamental ontology`;
- `not_established != false`.

## 1. Parameter-event correspondence ablation

The cubic Stage 11C architecture is copied with `Xi.event_correspondence` and its explicit semantics removed while O is left unchanged.

O still contains both typed role rows:

- `e1` / prediction anchor / Stage 11 physical event id;
- `e2` / measurement target / Stage 11 physical event id.

Therefore the correspondence can be reconstructed numerically from O. This does **not** restore the declared Xi typing resource. Stage 11C/11D validation must reject the ablated architecture as a well-typed cross-representation context.

Target classification:

`event_correspondence_reconstructible_but_typed_identity_lost`.

Thus the intended result is:

- numerical payload: `reconstructible`;
- typed identification: `lost`;
- covariance claim: `not_established`.

This is the direct Stage 11 analogue of the Stage 10F distinction between stored/reconstructible numerical forms and typed operational identity.

## 2. Missing lapse/Jacobian semantics

A second cubic architecture retains its correct numerical anchor/target lapse values but removes the Xi sentence specifying how lapse transforms under reparameterization.

The underlying Stage 11A/B trajectory is unchanged, so the stored numerical values can still reconstruct

`dq/dT=(dq/dlambda)/(dT/dlambda)`.

Stage 11D context validation must nevertheless reject the typed claim because the lapse/Jacobian transformation semantics are absent.

Target classification:

`lapse_semantics_missing_typed_claim_not_established`.

This case must remain distinct from an actually wrong Jacobian/lapse value.

## 3. Wrong lapse/Jacobian value

The cubic parameterization is deliberately assigned the identity-chart target lapse.

This has two independent witnesses:

1. Xi/context validation rejects the target lapse as inconsistent with the cubic parameterization;
2. using that wrong lapse in the relational derivative changes `dq/dT` away from the canonical momentum `p`.

Target classification:

`wrong_lapse_jacobian_numerically_refuted`.

Thus missing semantics is `not_established`, while a wrong numerical lapse with an explicit derivative witness is `refuted` for the tested construction.

`not_established != refuted`.

## 4. Consolidated false-positive family

Stage 11F consolidates seven controls:

1. orientation reversal `f_rev(lambda)=-lambda`;
2. non-injective square relabeling `f_noninj(lambda)=lambda^2` on the both-sign domain;
3. raw-equal-parameter event matching;
4. parameter-dependent O corruption;
5. parameter-dependent P corruption;
6. parameter-dependent R corruption;
7. parameter-dependent V corruption.

The orientation-reversal control is required to exhibit decreasing raw labels on the sampled source sequence rather than being rejected only by a metadata flag.

The square-map control is required to exhibit explicit collisions between distinct signed source labels.

The raw-lambda control reuses the Stage 11B identity/affine witness in which equal numerical raw labels include physically different events.

The O/P/R/V controls reuse the Stage 11C validator and must all retain classification

`parameter_dependent_oprv_corruption_detected`.

## 5. Criterion mapping

- **46** — reversal, noninjective relabeling, raw-lambda matching, and parameter-dependent O/P/R/V corruption have explicit false-positive controls;
- **47** — no ablation/control result is promoted to metaphysical fundamentality or ontological becoming.
