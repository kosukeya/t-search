## Question

Stage 13D asks whether the Stage 13A–C finite two-constraint family can be organized into an explicitly typed multi-constraint gauge atlas whose quotient is generated by licensed `Phi_T` / `Phi_X` connectivity rather than by copying stored physical-orbit labels, while keeping distinct physical Dirac data and two-clock relational content intact.

The executable questions are separated:

1. type physical orbit, representative, constraint generator, constraint basis, path word, event, clock, and modal continuation as distinct node roles;
2. construct the atlas from all licensed single-generator `Phi_T` / `Phi_X` arrows;
3. recover the quotient from graph connectivity without using stored `orbit_id` values to perform the union;
4. verify exactly four quotient classes of nine representatives each;
5. descend Dirac and two-clock relational payloads to those quotient classes;
6. verify that the compensated `TX` and `XT` path words from Stage 13B descend to the same quotient payload;
7. separate loss of typed path-word / compensator provenance from finite numerical reconstructibility;
8. keep gauge path words distinct from modal continuation and physical temporal history.

Stage 13D does **not** yet lift the O/P/R/V/Xi future-measurement architecture. That remains Stage 13E.
