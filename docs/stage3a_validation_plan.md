# Stage 3A Validation Plan

Stage 3A validation is intentionally narrow.

The repository test suite must verify:

- complete eight-state enumeration;
- full-space bijectivity of `U_rec` and `U_scr`;
- self-inverse behavior of both maps;
- rejection of a non-bijective control map when reversibility is claimed;
- exact four-state canonical boundary distribution;
- exact four-trajectory forward ensemble;
- forward dynamical validity;
- modeled history reversal as an involution;
- reverse dynamical validity using inverse maps in reverse order;
- preservation of full-state probability mass and Shannon entropy.

Passing these checks establishes only a reversible substrate. It does not establish a record relation or temporal orientation.
