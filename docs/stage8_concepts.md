## Quantum Actuality and continuation

`A_Q(D)` is the currently declared constrained quantum actuality at anchor `D`; it is not a complete future.

A `QuantumContinuation` is a physically admissible executable completion beyond `D`.

`QExt(D)` is the set of physical continuation-equivalence classes.

`same current quantum Actuality != same complete continuation`.

`QExt represented != ontically real futures by definition`.

## Epistemic quantum Potentiality

`EPot_Q(D)` is a typed set of live continuation hypotheses in a model that already contains selected complete continuation `h*`:

`M_E^Q=(QCarrier,D,h*,q_E)`.

`OPot_Q(D)` is the typed extension structure of:

`M_O^Q(D)=(QCarrier,D,QExt(D),K)`.

The Stage 8B ontic model is frozen/slots and stores carrier plus extension weights only. Its declared schema has no selected continuation, selected history, selector, seed, precomputed outcome, latent branch selector, singleton continuation datum, or arbitrary instance dictionary.
