## Construction

- epistemic selected-continuation model: `M_E^QR=(QRCarrier,e1,h*,q_E)`;
- ontic-extension model: `M_O^QR(e1)=(QRCarrier,e1,QExt(e1),K)`.

## O_QR

The public interface contains:

- current density matrix;
- current target-memory record distribution and information;
- common directional-record/accessibility statistics;
- future-signature outcome set and probabilities;
- explicit observed evidence after update.

It deliberately excludes hidden selector, model type, and typed q_E/K field names.

The directional interface is validated per continuation before being exposed. It is therefore not a branch-weighted arrow.

## Main controls

Matched weights `q_E=K=(0.5,0.5)` give equal public views even though privileged modal structure differs.

Changing hidden `h*` from h_L to h_R does not change the public view.

Changing only K to `(0.75,0.25)` changes the future-signature prediction while preserving current density, record content, and direction. This shows that the operational interface is genuinely sensitive to `V_weights` without making the current arrow weight-derived.

Explicit external evidence updates both models by the same likelihood rule. The epistemic selected continuation is preserved; the ontic update remains selector-free.
