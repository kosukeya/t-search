# R0〜R1b 補足 — 周期境界が持ち込んだ条件

2026-09-05。基準 commit `bd02f1a7a0a944c5bd60a395fcdcdaad67304f1d`。ユーザーが採用した目的は **blockness／becoming への理解を深めること**。これは R1b 後に明示的に依頼された境界比較であり、元の候補の救済や新規性探索の再開ではない。

**結論:** 終端を始点へ戻す条件を外すと、同じ装置・入力・二つの遷移で一回の読み出しが成立する。その全履歴は一つの制約を満たす状態として記述できる。R1b の障害は「記録を作ること」一般ではなく、「記録作成後も同じ周期の初期状態へ戻すこと」と追加操作を禁じた予算の組合せに由来する。[総括と解釈](t_search_r_series_synthesis.md)を参照。

## 固定したもの・変更したもの

A/B/C/M/N、運動学的次元108、既存の B/C/M 支持次元14、N の準備 `|0>`、コピーなし／ありの二設定、A/e2 の最終ポインタ測定を固定する。CNOT は M の指定基底のビットを N に記録する操作。未知の量子状態全体を複製する操作ではない。

R1b の `e0→e1→e2` の辺とその内部順序を保持し、`e2→e0` の制約項だけを外す。N の逆操作・環境・追加の記録媒体・周回カウンタは加えない。「終端を閉じない」は履歴の境界条件を指し、環境との交換を追加する意味ではない。e2 以後の存続・反復・消去は仕様の外に置く。

## 二辺の制約と証明

R1b と同じ記号を使う。S は28次元支持空間から36次元の残りの系への等長埋め込み、D は M→N の CNOT、T は既存の支持上の遷移。`s=0,1` に対して

`U0=D^s T_10`, `U1=T_21`, `F0=I`, `F1=U0`, `F2=U1U0`。

`A_j=<t_(j+1)|⊗S† − <t_j|⊗U_jS†` を j=0,1 についてだけ定義し、

`H_open=(A_0†A_0+A_1†A_1)/2 + I_A⊗(I−SS†)`。

第二項が支持空間を固定し、最初の二項が二つの遷移を固定する。全28次元の種状態 v に対して

`J_open v=(1/√3)Σ_(j=0)^2 |t_j>⊗S F_j v`

と置くと、`H_open J_open=0`、`J_open†J_open=I`。逆に零エネルギーなら各非負項が零なので、支持上の三成分は v, U0v, U1U0v で尽くされる。したがって零空間の次元は28で、N=0 とした任意の14次元入力が許される。混合入力にも線形に拡張できる。

周期モデルではさらに `U2U1U0 v=v` が必要だった。二辺のモデルにはこの方程式がない。これは境界条件の変更であり、物理空間への射影・再正規化ではない。閉じた周期の一周条件は既知の結果で、例えば [Churilov, Corollary III.3](https://arxiv.org/html/2608.05748v1) に対応する。本補足の導出は同論文の他の主張には依存しない。

## 比較結果

| 読み出しありのモデル | 物理次元 | N=0 で許す入力次元 | ポインタ結合回数 | 標準入力の最終 N 分布 |
| --- | ---: | ---: | ---: | --- |
| 閉じた周期・single | 21 | 7 | 一周期1回 | 標準入力は不適格。分布を作らない |
| 閉じた周期・compensated | 28 | 14 | 一周期2回 | (1/2, 1/2) |
| 終端を閉じない・open | 28 | 14 | 対象区間1回 | (1/2, 1/2) |

コピーなしの open は物理次元28、入力次元14、標準入力の N 分布は (1,0)。両設定は A/e0 で同じ準備を持つ。コピーありでは N は e1 から e2 まで記録を保持する。永久保存や同じ装置での無限反復を示したものではない。

**open と compensated の零空間は同じである。** 両者の F0,F1,F2 は同一で、compensated の閉じる辺は `U2=(U1U0)†`。したがって任意の open 履歴が、その閉じる辺の条件も満たす。逆に compensated の履歴は必ず最初の二辺を満たす。種座標を揃えると J 自体も一致する。コピーなしでも、対応する off 周期モデルとの同じ関係が成立する。

数値では、零空間射影の差は最大 `2.28e-15`、全種状態に対する履歴写像の差は最大 `2.18e-15`。一方、制約行列の差の Frobenius ノルムは約5.29150、全108次元における最小正固有値は open で1/2、比較する周期モデルで1。**同じ零空間という結果を、制約演算子全体の同一性や、任意の追加介入まで含む物理理論の同値性へ広げない。** 後者の比較は今回行っていない。

閉じた single の零空間は open の真の部分空間で、7次元分を除く。open の標準履歴に閉じた single の制約を作用させたノルムは約0.408248であり、終端を閉じる条件が実際に効いていることも確認した。

## 記録と時計変更

N=0 の準備からコピーありの装置を縮約すると、最終測定の Kraus 演算子は `K_n=T_21 P_M,n T_10` となる。全14次元入力で `Σ K_n†K_n=I`。数値残差は `6.86e-15` 未満。全履歴密度演算子 `ρ_hist=J_open(ρ⊗|0><0|)J_open†` と、各事象へ条件付けて得る状態は、同じ準備・同じ二つの操作を表す。

A/C の全3読みで還元写像を導き直した。支持階数は28、誘導計量を使った逆写像と全入力の確率保存の残差は最大 `2.68e-15`。比較するのは常に **A/e2 として定義された同じポインタ事象**。C の同じ整数読みで裸の N を測る別の問いと混同しない。

ここで同値なのは、この固定した実験の履歴状態と対応する結果統計である。装置変更後の制約族、独立な資源制約付き介入集合の閉性、循環的な測定後状態の再準備までは示していない。測定相互作用と記録を履歴の中へ含める考え方は [Hausmann et al., §3.2](https://arxiv.org/html/2308.10967v4) に、操作ごとに制約族を比較する区別は [Baumann–Lock, §VI.2](https://arxiv.org/html/2603.08845v1) に先行例がある。今回の有限構成をそれらの連続時計モデルと同一視しない。
