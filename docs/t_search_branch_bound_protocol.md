# R5後続補足 — R3認定から条件付き誤差を保証する：実施仕様

2026-10-31、branch-bound-v1。基点は未マージ[PR #24](https://github.com/kosukeya/t-search/pull/24)の 5689496279c4c2519bf459fc26a068e838006e7a。mainはR5c統合 4a0f32d8fdd87f7daa6a3f0a9cac4c81b6fac5c2。同じ研究ブランチで、[分枝同定監査](t_search_instrument_audit.md)の厳密ユニタリ例外と「具体的な条件付き予測の誤差保証」という次の判断を引き継ぐ。旧仕様・報告・主張台帳・実装・JSONは変更しない。

## 一つの問い・理由

**R3の非選択回復チャネルの忠実度下限Lと、対象入力における分枝確率p_b>0から、その分枝の出力が理想的な回復出力とどれだけ違うかを保証できるか。**

前回は、非選択チャネルと分枝確率から個々の分枝写像を一般には同定できないと分かった。ただし同定できないことと、全候補に成り立つ誤差上限がないことは別である。今回はフルの装置同定に拡張せず、恒等目標への条件付き予測の十分保証だけを求める。

## 比較・仮定・許容操作

- 対象はR3と同じ固定した量子ビット入力→量子ビット出力の非選択CPTP写像Λ。完備な公開フラグ付き操作を {Φ_b}、ΣΦ_b=Λとし、装置は入力や検査設定ごとに切り替えない。各分枝のKraus行列は未知でもよい。
- 理想出力は入力ρをそのまま回復したρ。実際の条件付き出力はΦ_b(ρ)/p_b(ρ)、p_b(ρ)=Tr Φ_b(ρ)>0。前回のR5入力状態対に同じ操作を適用する比較から、同じ入力への実際の回復と理想回復の比較へ変更する。条件付き状態と分枝写像の同定も区別する。
- R3の八条件、厳密な四正答確率、固定次元・信頼準備測定・同一CPTP・リセット・漏れ/選別なしを引き継ぐ。p_bはその入力での厳密確率または別に正当化された下限であり、四正答確率だけから未知のp_bを認定したとはしない。
- 参照Rは証明と独立検算にだけ使い、装置は操作しない。R3で既に用いる参照付き診断であり、R5の観測者へ新しい相関資源を渡す実験ではない。環境アクセス、内部時計、物理装置の追加は行わない。
- e=1−Lは過程忠実度欠損の上限。R5の状態対の全変動距離εとは別量。候補上限 min(1,√(2e/p_b)) を、Krausの恒等成分/トレース零成分の分解と純粋状態への距離から解析し、稀な分枝に対する限界も検証する。
- 新しい認定器は作らず、既存R3認定器を四確率と宣言だけで呼ぶ。一般性は解析、有限行列の検算は補助とする。文献に依存する境界と規約は一次本文で確認する。

## 固定する検算・成功/中止条件

主対照は K_0=√(1−q)I、K_1=√q exp(iαZ)。q={1,10^-2,10^-6}、α={0,π/12,π/2}の9操作に固定する。L=F_e=1−q sin²α、＋入力の分枝1でp=q、条件付き距離 |sinα| を照合する。q→0、α=π/2の解析で、全体性能が恒等へ近付いても条件付き誤差1が残ることを調べる。

非ユニタル対照は振幅減衰 K_0=diag(1,√(1−q))、K_1=√q |0⟩⟨1|、q={0,10^-2,10^-6,1}の4操作。二分枝を公開する場合と、二Krausを一分枝へまとめる対照の両方を使い、入力依存確率と混合分枝も確認する。計17操作。入力は0,1,＋,＋i,I/2および本文で明示する一つの非対称混合状態の6条件。

成功は、(1)十分上限の証明と正確率/理想出力の指定、(2)p下限を除けない反例と平方根依存の確認、(3)全Kraus完備性・全4行列単位・独立Choi/Bell値・既存R3境界との照合、(4)純化した入力と縮約出力双方での上限照合、(5)誤差予算・仮定・未実施事項・主張台帳の保存。零確率分枝は解析で特定し正規化しない。絶対数値許容差1e-10、相対0。分布・固有値・認定入力をクリップしない。

上限が解析または対照で破れたら原因と否定的結果を保存し、数値走査で一般性を補わない。入力確率を未知のまま推定済みと扱う、有限標本やSPAMを理想確率の余裕で隠す、最適回復性能・特定内部操作・単一事実の現実化を認定する必要が生じた場合はその主張を保留する。
