# 校正誤差予算を含む条件付き予測保証 — 実行前プロトコル

日付: 2026-11-02（Asia/Tokyo）。基点は未マージの[PR #24](https://github.com/kosukeya/t-search/pull/24)、研究ブランチ research/r5d-synthesis の 50f27e6f0762966570910df6564cc4a6c26a3839。mainはR5c統合 4a0f32d8fdd87f7daa6a3f0a9cac4c81b6fac5c2。前回から外部更新・レビュー追加なし。旧仕様・実装・認定器・JSON・過去の判断は保持する。本書を今回の計算より先に記録する。

## 一つの問い・選定理由

**外部の根拠を持つ準備・測定の誤差上限があるとき、前回の有限カウント保証をどこまで保守的に補正でき、測定回数の増加だけでは何が解決しないか。**

[有限カウント監査](t_search_finite_counts.md)は理想的な準備測定を信頼した。今回はこの仮定だけを既知の誤差予算へ緩める。未知SPAMの推定、校正手続きやIIDの検証まで拡大しない。無校正の否定的対照も同じ問いの識別限界として扱う。

## 固定する仮定・許容操作・変更

- 恒等回復を目標とする固定量子ビットの同一CPTPチャネルΛ、同一の完備な公開フラグ付きインストゥルメントを保つ。次元・配線・リセット・設定漏れ/試行選別なし・バッチ内IID・固定計画・五母数への失敗予算α/5は前回通り。公開フラグは実際の操作を定義するラベルとし、隠れた理想ラベルとの一致は認定しない。
- 各検査j=0,1,＋,−で、名目入力ρ_jと実際の入力σ_jの距離D=半トレースノルムはa_j以下、正答測定の実際の効果と名目射影の作用素ノルム差はm_j以下と仮定する。これは独立に正当化された決定論的上限を仮定した感度解析であり、データから推定した校正値ではない。
- 対象フラグの測定バッチでは名目入力ρと実際の入力σの距離をa_*以下とする。理想入力ρでの条件付き出力と、実際のσでの条件付き出力を別の対象として定義する。前回の対象は前者。未知の分枝行列の同定は要求しない。
- 前回の片側下限ℓは実際の装置が返す確率の下限。|π_j−実際の正答確率|≤a_j+m_jを導き、正答下限と理想入力の分枝確率下限を補正する。校正上限自体を信頼区間で与える場合の追加失敗予算は未実施。旧認定器のexact_probabilities契約は変更しない。

## 評価・成功条件・中止条件

1. 効果の変動、トレース距離の収縮、前回の忠実度/分枝上限を用いて一般式と同時被覆を導く。一次資料の対応箇所を確認する。既知原理の適用を新定理とは呼ばない。
2. 前回の構成カウント6例（各バッチn=1000,100000,20000000、フラグ頻度0.5/0.01）に、全四検査でa_j=m_j=η/2、η=0,10^-8,10^-6,10^-4、a_*=0を固定して24例を計算。さらにn=20000000・フラグ頻度0.01・η=0でa_*=0,0.005,0.01の3例を評価し、零予算が旧結果へ戻ることを照合する。実機ショットとは扱わない。
3. Z検査は固定、名目X検査の準備・測定軸だけを(cosθ,0,sinθ)へ傾ける。θ=0,π/12,π/4,π/2、チャネルI/Zの8例で、準備距離・効果ノルム・四正答率・Bell状態による忠実度・名目/実際入力の出力距離を独立な2×2/4×4行列計算と解析式で照合する。θ=π/2で全五確率が一致する識別不能例を保存する。共通の座標回転とは混同しない。
4. 有限回数を無限へ近づけても残る保証式の床を解析する。η=10^-4、分枝確率0.01、目標距離0.01を固定例とし、誤差予算の必要な小ささをこの十分保証の条件として解く。実際の物理誤差の下限とは呼ばない。
5. 許容差1e-10、相対0。浮動小数点の補正は保守側へ丸め、80桁Decimalの独立評価と照合する。既存の有限カウント再現コードも再実行する。掲載コードの再実行、相対リンク・主張ID・表・staged whitespace、旧blob/hash保持を確認し、結果・限界・台帳・README/roadmap/実行ログを同期する。

成功は導出、24+3計算、8行列対照、識別不能例、保証式の床、再現性と記録を全て満たすこと。無校正データから校正を認定する、IIDを検証済みと置く、反例を座標ゲージだけに帰す、予測保証を単一事実や存在論的becomingの証明とする必要が生じた主張は保留する。文書のみの変更では全体pytestをローカル反復せず、基点CIと新headのCIを別に記録する。成果物は docs/t_search_calibration_budget.md。
