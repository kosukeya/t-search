# R5後続補足 — 条件付き予測の保証：監査仕様

2026-10-29、`conditioning-v1`。基点は未マージPR #24の `7a9c8d644cc06b618bf5c3990bd07d12259a4222`。mainはR5c統合 `4a0f32d8fdd87f7daa6a3f0a9cac4c81b6fac5c2`。R5a〜dの本文・証拠を保持し、同じ研究ブランチ・PRで補足する。R5の閉じた課題の結論を書き換えず、新しい大規模実験系列は設けない。

## 一つの問い

**全結果についての予測差がε以下というR5の保証から、ある記録・成功フラグに条件付けた予測の保証を得るには、何を追加で指定する必要があるか。**

R5aは選別した成功結果だけの比較を全結果保証から除外し、R5dは条件付き状態と非選択状態を区別した。今回は、その留保を定量化する。比べるのは「無条件のε保証を同じ精度の条件付き保証と扱う推論」と「分枝確率・条件付けの種類を指定した保証」である。

## 定義・仮定・許容作業

- R5の事象2、ρGとF1デフェージング対照、Q=SF1F2・G=QEを引き継ぐ。原則は同じQ上の完備な量子操作と全結果ログ。Eへ再結合しない。
- 各分枝ΛbはCP、全分枝の和はTP。両仮説で同じ装置・同じ分枝ラベルを使う。条件付き比較は両側の分枝確率r,s>0で定義し、零確率の条件付き状態を作らない。
- 一般の条件付き上限を全結果のトレース距離から導く。分枝確率の下限を追加した保証と、相対的な演算子の大小関係からの保証を区別する。
- 反例はR5の既存許容入力族で、ρS=|ψp⟩⟨ψp|、|ψp⟩=√p|0⟩+√(1−p)|1⟩、0<p≤1/2とする。Q内のフィルターKs=diag(1,√(p/(1−p)))、Kf=diag(0,√((1−2p)/(1−p)))をSへ作用させ、成功・失敗を両方保持する。その後は既存Q復号・位相読出しを使う。pと位相は既知の状態対の定義であり、どちらの仮説かを知らせる情報ではない。
- 本来のF1のZ記録bへのLüders条件付けも比較する。フィルターの成功フラグsとF1の記録値bを同じものと扱わない。
- 一次資料はCPTP写像・トレース距離縮小の本文を確認する。一般性は解析を根拠とし、既存ゲートでの有限行列検算は補助とする。旧JSON・実験コード・テストは変更しない。

## 評価・成功・中止条件

成功は、(1)分枝確率を明示した上限と証明、(2)無条件差が小さくても条件付き差が残る反例、(3)失敗を含む全結果の差が元の保証内である確認、(4)元のZ記録に条件付ける場合の正の結果、(5)入力の偏りによる小差と環境重なりによる小差の適用範囲、(6)主張・限界・再現手順と進捗の保存である。単一結果の実現や存在論的becomingの判定は行わない。

有限検算はp={1/2,10^-2,10^-4,10^-6}、θ={0,π/3,arccos(10^-2)}の12条件に固定し、完備性・分枝確率・全結果分布・条件付き距離・解析値を照合する。一般上限は非対角なフィルターによる不等確率分枝でも検算する。絶対数値許容差1e-10、相対0。ショット実験や信頼区間は付けず、分布を切り捨て・選別して無条件の成功にしない。

零分枝の正規化、Eアクセス、仮説依存の装置変更、未知入力のp推定を必要としたらその主張を保留する。成果物は `docs/t_search_conditioning_audit.md`（導出・検算手順・主張台帳を含む）。Markdownだけの補足として、必要な文書検証と基点／新headのCIの区別を行う。
