# 記録フィードバック下の正の分枝確率下限 — 実行前仕様

2026-11-06。基点は [4e962b9](https://github.com/kosukeya/t-search/commit/4e962b9b42918b841e26775737e95cd62e7b5088)、既存の research/record-feedback-average と [Draft PR #25](https://github.com/kosukeya/t-search/pull/25) を継承する。mainは96aea72で、R5dと時間平均までの六補足を統合済み。前回以降の外部コミット・レビュー追加はない。

**一課題。** 過去の記録で処理が変わる固定長の実験で、成功数から予測可能平均への有効な正の下限を得られるか。[前回の六条件](t_search_kl_feedback_protocol.md)では旧KL下限の被覆が三条件で崩れ、有効な加法下限は全条件でゼロだった。旧条件をそのまま使い、下限の計算法だけを変える。

- 二値スコア $X_t$ と過去の全古典記録 $F_{t-1}$ に対し $p_t=E[X_t\mid F_{t-1}]$、$S_N=\sum_t X_t$、対象は実現経路に沿う $\mu_N=\sum_t p_t/N$。五設定を共用するブロック、量子リセット、校正上限は前回と同じ。数値対照では校正予算ゼロとし、第五設定の分枝確率だけを評価する。
- 観測前に指数の底を **4**、片側予算を **0.01** と固定する。条件付き平均で正規化した積と算術・幾何平均の不等式から、$L_4=\max(0,((4^{S_N}/100)^{1/N}-1)/3)$ を導く。倍率の探索、データに応じた選択、加法下限との最大値の採用は評価対象外。指数の底は計算と正負判定が簡潔な固定候補として選ぶ。
- $N=100,1000,10000$、活動時 $p=1/1000,1/100$、成功数上限32、旧KLの切替境界を全て維持する。切替後のゼロも含めて全N試行を使う。新しい下限で方策を選び直さない。固定pの非適応六対照も同じNとpで調べる。
- 評価は $L_4>\mu_N$ の確率、$L_4>0$ の確率、両者の共通部分と、加法下限との比較。活動期間 $\tau$ に対し $\mu_N=\tau/(DN)$、$D=1/p$ なので、失敗判定は $4^s(DN)^N>100(DN+3\tau)^N$ の整数比較で行う。全終端質量を整数DPで集計する。独立な80桁Decimalの逆根・後向き再帰を全六条件で照合し、非適応対照は厳密二項和を使う。前回の失敗確率分子を照合して、方策が同一であることを確認する。
- 成功条件は一般の予測可能二値列での固定Nの被覆の証明、全六条件の比較、確率の独立照合（絶対差 $10^{-50}$ 以下）、陰性・保留結果と再現手順の保存。六条件で正の下限が得られなければ、その結果を保存する。境界・確率・証明が一致しなければ該当結論を保留し、倍率や条件を追加しない。比較の範囲を示すため、$N=100,S=50$ の構成カウントと $S=0,N$ の端点を確認する。
- 五設定の同時保証に使う場合は、各スコアの手法と予算を事前に決めるという条件を明記する。実機の妥当性や非自明な量子距離保証の頻度は今回の範囲外。成果物は報告・再現コード・主張台帳と進捗文書。
