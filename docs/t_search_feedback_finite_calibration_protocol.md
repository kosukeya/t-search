# 有限校正から同時読出しの保証へ — 実行前仕様

2026-11-13。基点 ac97ebaec5237c99b704de446af1a40d1a355900。同じ [Draft PR #25](https://github.com/kosukeya/t-search/pull/25) を継承する。

**問い。** 前回所与とした射影失敗の検出効率の下限を、別の有限校正バッチで選ぶとき、全経路の誤発行を5%以下に保てるか。校正結果を本試験へ移す仮定と、その仮定を破ったときの限界を検証する。[前回の補正](t_search_feedback_readout_calibration.md)

- 既知の真の失敗を入力でき、検出ビットは固定効率で独立なベルヌーイ列とする。校正は本試験前に固定32または64回。候補下限は1/4、1/2、3/4、7/8。各候補の厳密二項上側確率を1%と比較し、採用可能な最大候補を一つ選ぶ。候補なしは不発行。
- 主条件では校正効率が本試験の全試行・過去での真の失敗検出効率の下限であると仮定。本試験は固定128試行、入力＋、正確なフラグと準備、量子リセット、前回のフラグフィードバックを維持する。選んだ下限を固定して前回の重みを使い、積25以上で発行する。本試験の誤り予算4%。
- 校正効率・本試験効率・真の失敗率の対照を (1,1,0)、(3/4,3/4,0)、(1/4,1/4,3/8)、(1,1/4,3/8) とする。最後は移送仮定を破る対照。前回のコヒーレントZ回転を用い、真の距離は失敗率の平方根。成功側の誤分類は数値対照では0。
- 成功条件は校正下限と全体予算の解析、八条件の有理数計算、フラグ数と条件付き二項和を使う計算と、三値の前向き整数DPとの厳密照合。校正閾値の隣接点、下限なし、移送条件が成り立つ悪い対照の誤発行を確認する。移送違反が5%を超えなければその結果を保存する。照合不一致は結論を保留し、条件は追加探索しない。実機で真の失敗を準備できる根拠や、効率の移送を実証する測定は別途必要。
