# 記録フィードバック下の分枝状態を同時読出しで保証する — 実行前仕様

2026-11-07。基点は [76564dd](https://github.com/kosukeya/t-search/commit/76564dd30f41e712af29646bf4fc73be6dc77920)。既存の research/record-feedback-average と [Draft PR #25](https://github.com/kosukeya/t-search/pull/25) を継承する。

**問い。** [前回](t_search_feedback_count_bound.md)の正の分枝確率下限は分枝内の状態距離を保証しなかった。入力とフラグを固定し、同じ試行でフラグと目標射影を読むと、履歴に沿う平均の分枝状態に対し距離1/2以下を有限記録から保証できるか。既存の非選択忠実度に基づく十分上限が1になる条件を対照にする。

- 固定長、入力と目標は量子ビットの＋、対象フラグを1とする。古典的な過去だけで各試行のインストゥルメントを選び、各使用は量子リセット。準備、目標射影、フラグ配線を信頼し、校正誤差は0とする。フラグなし・フラグ付きで射影成功・フラグ付きで射影失敗の三値を全て保存する。第五設定をこの同時測定へ変更し、他の四設定を判定に使わない。共通の履歴と重みで定義した予測可能平均を対象とする。
- 目標距離1/2と全経路の誤発行予算0.05を事前固定。三値の倍率を順に1、5/4、1/4とし、全試行の積が20以上で保証を発行する。分枝質量が0の経路は対象状態が未定義であり、そこでの発行も誤りに数える。選択後の条件付き誤り率は別に集計する。
- 数値対照は N=32,64、初回と直前フラグなしでは p=1/4、直前フラグありでは p=1/2。フラグ付き射影失敗率 θ=0,1/4,1/2,1 を固定する。フラグなしはZ。フラグ付きは確率 θ の I/Z 混合、または同じ射影確率を持つコヒーレントなZ回転。二つの装置の観測分布と状態距離を比較する。全試行p=0の端点も解析する。
- 成功条件は一般の予測可能三値列での被覆の証明、八条件の発行確率・無条件誤発行・発行条件付き誤りの正確な評価、量子行列との照合。三値整数DPを、フラグ数分布と条件付き二項和に分けた有理数計算と厳密に照合する。行列の許容差は絶対1e−12。既存上限との比較は真の過程忠実度と分枝確率を与える対照に限定する。
- 境界・確率・行列が一致しなければ対応する結論を保留する。無発行や識別不能も保存し、条件や倍率を追加して有利な例を探さない。一般の入力・再条件付け・量子メモリ・実機校正は今回の範囲外。報告に再現コードと主張台帳を載せ、進捗文書と同期する。
