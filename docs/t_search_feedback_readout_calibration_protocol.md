# 同時読出しで射影失敗を取り逃がす場合の保証 — 実行前仕様

2026-11-08。基点は f2d7ef2c019b0f2d354739d78eadd837cb465beb。同じ research/record-feedback-average と [Draft PR #25](https://github.com/kosukeya/t-search/pull/25) を継承する。

**一課題。** [前回](t_search_feedback_joint_readout.md)の同時読出しは校正誤差ゼロを仮定した。真の射影失敗が成功として記録されるとき、失敗検出効率の独立な下限から、分枝状態距離1/2以下の固定長保証を回復できるか。前回と同じ古典的な過去に応じた制御、量子リセット、固定入力＋、固定対象フラグを用いる。

- フラグと準備は正確、射影の後段だけを古典的な二値読出しとする。真の失敗を失敗と記録する条件付き確率には、全履歴で一様な既知下限 η>0 を課す。真の成功を失敗と記録する誤りも許す。試行の欠落やフラグの誤分類は対象外。実機校正は行わない。
- 目標距離1/2と全経路の誤発行予算5%を維持する。倍率をフラグなし1、記録上の成功 1+η/4、記録上の失敗 η/4 として積20以上で発行。比較は前回の未補正倍率とする。
- N=64,128。フラグ確率は直前フラグなし（初回含む）なら1/4、ありなら1/2。真の失敗率 θ、実効効率、仮定する下限 η の組を (0,1,1), (0,1/4,1/4), (3/8,1/4,1/4), (3/32,1,1/4) とする。成功側の誤分類はこの数値対照では0。フラグ分枝は前回のコヒーレントZ回転とし、距離は√θ。後ろの二つは共通の下限ηの下で全記録分布が一致する対照。
- 成功条件は補正の固定長証明、事前固定八条件での発行確率と誤発行率の厳密比較、同一分布の構成、独立照合。フラグ数の有理数DPと条件付き二項和を全条件で計算し、N=64を三値過程の整数DPでも照合する。零フラグの端点とη=1での旧則との一致も確認。矛盾時は当該結論を保留し、対照は追加探索しない。5%超過がなくても陰性結果を保存する。既存報告は履歴として保持する。
