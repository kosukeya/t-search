# R5後続補足 — 有限カウントからの条件付き誤差保証：実施仕様

2026-11-01、finite-counts-v1。基点は未マージ[PR #24](https://github.com/kosukeya/t-search/pull/24)の d0b65de9a673f477e497153ba9529f138210c277。mainはR5c統合 4a0f32d8fdd87f7daa6a3f0a9cac4c81b6fac5c2。同じ研究ブランチで[前回の分枝上限](t_search_branch_bound.md)の「Lとpの根拠に有限標本を含める」課題を一つ進める。既存仕様・実装・認定器・JSON・過去の判断を保持する。

## 一つの問い・選定理由

**固定した五つの有限測定バッチから、忠実度下限と対象入力の分枝確率下限を同時に作り、前回の条件付き距離上限を所定の被覆率で使えるか。**

前回は厳密なBorn確率を使った。無失敗の観測頻度をそのまま確率1として旧認定器へ渡すと、条件付き誤差0を誤認定し得る。一般の未知SPAMまで広げず、この統計的な欠落だけを補う。

## 固定する条件・許容操作・変更点

- 固定量子ビット・恒等回復目標・同じ完備なフラグ付き処理、信頼する準備測定、リセット、設定漏れ/試行選別なしを維持する。各バッチ内は固定した確率の独立同分布Bernoulli試行と仮定する。ドリフト・未知SPAMは認定しない。
- 入力0,1,＋,−の四つの非選択正答カウントと、事前指定した入力ρ・フラグbの出現カウントを使う。失敗・不検出を含む試行を保存し、成功後のサンプルだけで母数を変えない。分枝・入力・バッチサイズ・信頼予算は事前固定。任意停止、結果を見てからの分枝選択、反復して通るまで測る使い方を除く。
- R3の exact_probabilities 宣言を頻度データに対してTrueにはしない。旧認定器は変更せず呼出しもせず、信頼条件のうち厳密確率だけを、明示した有限標本モデルへ置き換える。
- 二項上側尾のKL/Chernoff境界を反転した片側下限ℓを用い、五母数へ失敗予算β=α/5を配分。主例はα=0.05、要求する条件付きTV誤差τ=0.01。数学的被覆保証と数値計算余裕を区別する。
- L_low=max(0,(ℓ0+ℓ1+ℓ＋+ℓ−)/2−1)、r_low=ℓb。r_low>0なら前回の上限へ代入し、r_low=0なら条件付き主張を保留する。信頼水準を単一事実や装置の存在論の確率と解釈しない。

## 固定する評価・成功/中止条件

1. Bernoulliの指数モーメントから片側尾・反転区間を導き、合併則とR3/前回上限をつないだ同時被覆を証明する。原論文の指定箇所も確認する。最短区間や最適試行数は主張しない。
2. n={8,25,100}の全カウントで下限を作り、各真値j/100（j=0,…,100）の二項確率を有理数で全和して303件の周辺被覆を監査する。n=25の三カウント26³通りを、固定した位相反転フラグ模型のq={0.01,0.1,1/3,0.5,0.9}で照合する。
3. 浮動小数点の根を標準ライブラリDecimalの60桁計算と照合する。下限を1e-12だけ保守側へ戻す数値余裕を使い、αや物理誤差とは区別。一般的な機械検証済み数値ソフトウェアとは主張しない。
4. 四検査が全成功の整数カウント例を、各バッチn={1000,100000,20000000}、フラグ頻度={0.5,0.01}の6例と、n=100でフラグ回数0/1の2端点に固定する。これらは構成例であり、実機測定・大量ショットの実行とは報告しない。
5. 前回の稀なZ位相反転分枝で、頻度を直接代入する「誤差0」主張の偽保証確率を解析する。n=100でq=1−(2/3)^(1/n)を対照とし、正しい同時保証と比較する。

成功は、被覆証明、全カウント/高精度の独立照合、保留と非自明な保証の区別、頻度代入の否定的結果、仮定・限界・再現コード・主張台帳と進捗の保存を満たすこと。数値許容差1e-10、相対0。生カウントや真の二項確率を修正しない。下限の零切りと距離上限1は数学的な境界であり、観測値のクリップではない。

下限を上向きに丸めて成功へ変える、全結果を捨てる、有限走査で被覆の一般証明を代用する、校正/IIDを検証済みと置く、物理的な現実化を信頼水準から判定する必要が生じた場合は当該主張を保留する。成果物は docs/t_search_finite_counts.md（解析・検算コード・台帳）。README/roadmap/実行ログを同期し、文書チェックと旧blob/hash保持を確認する。既存の回復器・認定器・テスト・データは変更せず、新head CIを基点から分けて記録する。
