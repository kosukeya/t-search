# R5後続補足 — 分枝操作の同定とR3認定の窓口：監査仕様

2026-10-30、`instrument-v1`。基点は未マージ[PR #24](https://github.com/kosukeya/t-search/pull/24)の `622dda6fda2cdcc60cef0f8fe876328a2dfdc67a`。mainは `4a0f32d8fdd87f7daa6a3f0a9cac4c81b6fac5c2`。同じ `research/r5d-synthesis` で、[条件付き予測の監査](t_search_conditioning_audit.md)が残した装置の仮定を、[R3総括](t_search_r3_synthesis.md)と照合する。旧仕様・主張台帳・実装・保存JSONは変更しない。

## 一つの問い・選定理由

**非選択チャネルの認定と分枝確率が分かれば、結果bに条件付けた量子操作まで同定できるか。できなければ、どの追加データで今回の候補を識別できるか。**

前回は同じ既知の操作を両状態へ適用した。R3の四正答確率が認定する対象は非選択の合成チャネルであり、個々の分枝ではない。R3で既に扱った「同じ合成チャネルの内部実装の違い」を再計上せず、出力としてフラグを公開したときに予測が分かれるかを検証する。

## 仮定・許容操作・変更点

- 理想的な信頼準備・X/Y/Z測定、固定入出力量子ビット、同一装置の反復、リセット、設定漏れなし、全結果保持、厳密なBorn確率というR3型の条件を置く。有限標本やSPAM補正は扱わない。
- R5のQ支持を復号して得る論理量子ビットLを使う。独立なフラグBを追加する完備な二分枝操作をQ内で許し、Eには結合しない。復号はF1記録を消す。Bは元のF1記録値ではない。
- 変更するのは比較対象である。前回の同じ操作に対する入力状態対の距離ではなく、今回は同じ入力への二つの候補操作を比較する。これを前回の条件付き距離や「同じ操作」という仮定の反例とは扱わない。
- 候補族は $K_0^{(\alpha)}=e^{i\alpha Z}/\sqrt2$、$K_1^{(\alpha)}=Ze^{i\alpha Z}/\sqrt2$、$0\le\alpha<\pi$。解析は全入力演算子に対して行い、数値照合はα={0,π/8,π/4}に固定する。
- 非選択写像、フラグ周辺分布、フラグ付き出力を別々に比較する。α=0とπ/4を主反例とし、＋入力の分枝状態・全フラグ/出力同時分布を計算する。候補を取り替える比較であり、入力や検査設定ごとに未知装置を切り替えない。
- 追加情報はフラグとX/Y出力の同時確率。宣言した候補族での位相同定と、一般の量子ビット分枝写像を再構成する十分なデータを区別し、後者は四つの入力とX/Y/Z測定の線形な情報完全性で確認する。

## 評価・成功・中止条件

成功は、(1)全入力で等しい非選択チャネルと分枝確率、(2)正確率分枝で異なる状態、(3)全結果を保持した識別測定、(4)R3認定器の対象と条件付き予測上限の適用範囲、(5)追加データの十分性と残る信頼条件、(6)再現可能な検算・主張台帳・進捗保存を満たすこと。

解析の独立照合として、全4行列単位、正規化Choi/Bell重なり、分枝ごとの線形再構成、完備性・生の全結果確率を検算する。絶対許容差1e-10、相対0。零分枝を正規化せず、確率をクリップしない。反例にEアクセス、入力ラベル漏れ、失敗分枝の削除、仮説依存の測定が必要なら当該主張を中止する。一般の装置認定や存在論の識別が必要になれば範囲外として保留する。
