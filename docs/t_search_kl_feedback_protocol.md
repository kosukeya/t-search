# 記録制御下の旧KL下限 — 希少事象による被覆監査の実行前仕様

2026-11-05。基点は未マージ[PR #25](https://github.com/kosukeya/t-search/pull/25)の decbbc3089ab8334df48b572f27e28903b7b31ac、research/record-feedback-average。mainはR5dと六補足を統合した96aea72c205b130e5f6fc83e3abbc415bd5268abのまま。前回以後の外部コミット・レビュー追加なし。同じ系列を継承し、旧文書・陰性結果・実装・テスト・JSONを保持する。本書を計算前に記録する。

## 一課題・選定理由

**旧KL片側下限を予測可能平均へ移す方法は、過去の希少事象に応じる固定長制御で所定の被覆を保つか。**

[前回](t_search_record_feedback.md)のp_t∈{0,1/2,1}・n≤100では反例が見つからなかった。小さい確率と長い期間はその探索外であり、記録が後続へ作用する際の保証の適用限界を一回で判定できる明示的な制御クラスとして選ぶ。反例を探すだけで過去の陰性結果を否定したり、既知の確率原理を新発見とはしない。

## 固定する仮定・許容操作

- N=100,1000,10000と、初期確率p=1/1000,1/100の六条件、成功数上限K=32を観測前に固定。全N試行を実行する。各試行の確率は過去からpまたは0へ選ぶ。0へ切替えた後も、残りの試行の0結果を全て記録する。実験長の任意停止、試行選別、現在の乱数の先取りはしない。
- 旧下限の片側予算β=0.01。ℓ_KL(s,N)はkl(s/N∥ℓ)=log(1/β)/Nの根。累積予測成功数C=Σp_tを使い、対象はμ_pred=C/N。固定未知母数や将来の確率ではない。
- 過去の累積成功数sに対し、g_sはN·kl(s/N∥(g_s p)/N)>log100を満たす最大整数とする（s=1,…,K）。現在の試行tの終了後、t≤g_sなら次からp_t=0、そうでなくてもs=Kなら以後0とする。これ以外はpを続ける。g_sの探索は旧数値根を初期候補とし、根を挟む二つの整数点のKL符号を独立に認証して確定する。
- この制御は前回の古典フィードバックの許容クラスに収まる。量子対応はΦ_t,0=p_t Z(·)Z、Φ_t,1=(1−p_t)idとし、第五設定のフラグだけで次ブロックを制御する。五設定の共通処理・ブロック内固定・量子リセット・校正等は保持し、数値対照の校正予算は0。旧R3認定器は呼ばず変更しない。

## 評価・成功/中止条件

1. 初到達時に予測平均が固定され、KL下限がμ_predを超える条件を解析する。停止した制御と固定Nの試行数を区別する。量子インストゥルメントのCP/完備性・フラグ平均との対応を確認する。
2. 六条件で全経路の初到達確率を、分母(1/p)^tを共有する整数DPで正確に和する。到達済み/上限到達/継続中の質量を保持し、各時点で総和1を照合する。β超えは整数の交差乗算で判定し、乱数サンプルや浮動小数点の確率だけに依存しない。
3. 各g_sと隣の整数のKL符号を、有理数のlog区間で認証する。log x=2Σz^(2k+1)/(2k+1)（z=(x−1)/(x+1)）の40項と明示的剰余、2の冪による範囲縮小を使う。境界を認証できなければ80項へ増やし、それでも判定できない条件は保留する。80桁Decimalの逆根でも独立に整数境界を照合する。
4. 80桁Decimalによる別の前向き計算と整数DPの確率を照合。N=100の二条件では独立な再帰計算、明示的な最初の成功時刻での確率和も検算する。前回の加法下限が同じ終端で誤る確率を別に評価する。固定確率pをN回保つ非適応対照も保存する。
5. p_t=0,1/1000,1/100の量子対応を＋、0、(I+0.2X+0.3Y+0.4Z)/2で行列確認する。単一スコアの予算βを破ることと、五設定の全体予算α=0.05の量子誤差証明を破ることを混同しない。

成功は、六条件の正確な被覆評価、境界認証、独立照合、反例または陰性結果、加法法/非適応対照、量子対応、再現コード・仮定・限界・12件台帳・README/roadmap/実行ログの保存。確率の整数照合は完全一致、Decimalの差は1e-50以下、行列は絶対1e-10・相対0。掲載コード全文の抽出再実行、既存文書チェック、旧blob/hash保持、staged whitespaceも確認する。文書のみなら全体pytestはローカル反復せず、基点と新headのCIを別記する。

β超えがなければこの固定クラスの陰性結果を保存し、反例を得るため事後的に条件を増やさない。境界・確率・現在情報の不使用を照合できなければ該当主張を保留する。既知の独立列に対するKL定理、前回の加法定理、時間の存在論のどれを反証したとも扱わない。成果物は docs/t_search_kl_feedback_audit.md。
