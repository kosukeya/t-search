# 次期研究計画 — 記録が共有・保持される条件から blockness／becoming を理解する

2026-09-05。状態: **提案・未実施**。基点: [PR #19](https://github.com/kosukeya/t-search/pull/19) のマージ `83dd67346501d6f714d49cf7e962a39388f6a49e`。

目的は引き続き **blockness／becoming への理解を深めること**。次期系列を **R2：記録の共有・安定性とアクセス制約** と呼ぶ。本書の R2 は新しい理解・再現課題の提案であり、R0 の識別実験を自動再開する指定ではない。元の `pilot_gate = blocked`、R1b の周期候補不採用、Stage 17 未着手を維持する。研究結果や新規性の成立を本計画の作成によって宣言しない。

## 1. なぜこの方向へ進むか

[R0〜R1b の総括](t_search_r_series_synthesis.md)では、内部で記録が形成されることと、過程全体を一つの制約履歴で表せることが有限モデルで両立した。[境界補足](t_search_boundary_supplement.md)により、単一コピーを妨げたのは周期的復帰と操作予算の組合せであり、全体履歴表示そのものではないと切り分けた。

次に残る具体的な問いは、**形成された相関が、どの条件で、複数の観測者に読めて、読んでも壊れにくく、後にも利用できる記録になるか**である。「新しい事実が成立する」という言い方のうち、物理的な操作で検討できる部分を詳しくする。

| 次の候補 | 今回の判断 |
| --- | --- |
| 時計や基底を増やして共変性を再確認する | 優先しない。既存成果から理解がどう増すかが明確でない |
| 記録の共有・読出しによる擾乱・保持・回復可能性を比較する | 採用を提案。直前の成果と未解決点を一つの小モデルでつなげられる |
| 熱力学的な時間の矢や宇宙初期条件まで扱う | 後続候補。まず「保持される」と「不可逆」を区別する |
| 存在論的 becoming の実験的判定を直接狙う | 識別条件が未確立。追加仮定と異なる予測を示せる段階で再検討する |

## 2. 研究質問と用語

**中心質問:** 全体の過程を可逆な量子過程として記述できるとき、記録へのアクセスと許容操作の違いは、内部から利用できる「共有された安定な事実」の成立条件をどう変えるか。

- **R2-Q1 — 共有:** 二つの別々の記録から、同じ対象の指定基底の値をどれだけ正確に読めるか。一致するだけで対象について正しい情報を持つとは限らない。
- **R2-Q2 — 読出しと保持:** 読出しは、どの範囲の状態・相関をどれだけ乱すか。指定した記録雑音の後にも情報は残るか。
- **R2-Q3 — 回復:** アクセスできる部分系を変えると、未知の入力量子状態を回復できる範囲がどう変わるか。全体の可逆性と、部分系だけからの回復可能性を区別する。
- **R2-Q4 — 解釈:** 以上で説明できる「事実の成立」は何か。単一結果の現実化、未来の実在、時間経験について何が残るか。

本系列で「操作的な事実」と呼ぶ場合は、対象の指定変数について、明示した観測者が、指定精度で、指定した擾乱・保持条件の下で読める記録を意味する。世界に一つの結果が存在論的に追加されたという意味へ置き換えない。「観測者」はアクセス範囲と読出し装置で表し、意識や時間経験はモデル化しない。

計画時点ではこれらの書誌・要旨と関連する本文を確認した。R2a で実際に使う定義・式・仮定を固定する。体系的な最新文献監査や新規性の立証は未完了である。追加文献は、選ぶ操作・回復限界の根拠に不足がある場合に最大3件とし、論点が増えるだけの探索はしない。

現時点のリポジトリ内の差分は、R1b の一つのポインタの読出し相関から、**二つの独立な読出し窓口、読出し擾乱を評価する範囲、記録雑音、未知入力の回復**へ進むこと。Stage 1〜16 のアクセス・記録の既存台帳とも照合し、既存実装と同じ内容なら再利用する。これは文献に対する新規性の主張ではない。

## 4. 最小モデルと比較の範囲

最初は対象量子ビット S、記録 F1・F2、読出し側からアクセスしない環境 E の **4量子ビット**を使う。F1・F2 は二つの観測者が別々に読める記録媒体であり、観測者の全機能を表すものではない。入力 S は任意、他は |000⟩ に準備する。

基準回路は、順に CNOT(S→F1)、CNOT(S→F2)、最後に CNOT(S→E) または恒等操作を行う。比較するのは以下の3条件だけとする。

| 条件 | 用途 |
| --- | --- |
| 記録を作らない対照 | F1 と F2 が一致しても、対象について情報を持たない例 |
| F1・F2 へ記録、E とは相互作用しない | 共有される基底情報と、SF1F2 に残る量子コヒーレンスの関係 |
| F1・F2・E へ記録 | E を読めないときの SF1F2 の状態、および全体へアクセスした場合との違い |

初期基底、装置の準備、相互作用の順序を与えたモデルである。選好基底や時間の矢を導出したとはしない。既存の A/B/C/M/N の制約支持を単純な量子ビット積空間と同一視せず、新しい小さな教材モデルとして導入する。物理時計の選択・時計変更に関する既存結果を、この回路の外部指定の順序へ自動適用しない。

### 許容操作

1. 共有の評価では、各観測者は自分の Fi を固定した Z 基底で読む。互いの記録への量子操作や通信を読出し精度の前提にしない。結果の事後比較は共同確率を集計する手続きとして明示する。
2. 読出しは結果付き CP 写像と、その和である TP 写像を明示する。擾乱は選択結果で条件付ける場合と、結果を平均する場合を混同しない。
3. 保持の評価では、各記録に独立なビット反転チャネル `B_p(ρ)=(1-p)ρ+pXρX` を一回適用する。`p ∈ {0, 0.1, 0.25, 0.5}` の4点と解析式に限定する。これは指定雑音への耐性であり、長期寿命・熱力学的不可逆性の模型ではない。
4. 回復の比較は読出し・雑音を加える前の符号化チャネルについて行う。アクセス集合を **SF1F2** と **SF1F2E** に分け、各集合内の決定論的 CPTP 回復を比較する。全体へのアクセスは数学的対照であり、内部の観測者に実装可能と仮定しない。
5. 回復装置に未知入力の古典的記述を渡さない。既知状態の再準備を回復と数えず、ポストセレクションや失敗成分の捨て直しを用いない。有限な回路例での達成値と、任意の許容回復に対する上限証明を分ける。

### 指標

| 指標 | 具体的な評価 |
| --- | --- |
| 正確さ | 等確率の Z 入力に対する `P(読出し Fi ≠ 入力値)`。一般入力の検証とは役割を分ける |
| 共有 | 同じ入力実験における `P(F1=F2)` を、正確さと併記する |
| 読出し擾乱 | 非選択 Z 読出しの前後のトレース距離。SF1F2 と SF1F2E のどちらを比較するか必ず記す |
| 保持 | 指定チャネル適用後の正確さ・共有の変化。4点の数値だけでなく p の解析依存性を出す |
| 回復 | 参照量子ビット R と S の最大エンタングル状態を入力するチャネル検証。回復後の RS と元の状態の entanglement fidelity を評価する。R は装置から操作しない |

数値規模は本体4量子ビット、回復検証だけ参照を加えた5量子ビットまで。未知状態についての結論は少数の入力例ではなく、チャネルまたは解析式で支える。大規模探索、断片数の増加、回復アルゴリズム探索は本系列に含めない。

| **R2c：保持と回復の切り分け** | 同じモデルに限定した雑音4点と、二つのアクセス集合の回復比較を追記する | 雑音耐性とアクセスに起因する回復不能を分け、回復の達成値と上限の根拠を示せる |

R2a は文献・定義ノート、R2b は最小の実行可能な研究単位とする。予定ファイルは `docs/t_search_r2_records_spec.md`、`experiments/r2_shared_records.py`、`results/r2_shared_records.json`、`tests/test_r2_shared_records.py`、`docs/t_search_r2_synthesis.md`。これらは現時点では未作成である。段階を増やして計画だけを延長せず、R2a の仕様で R2b を実施できる粒度まで絞る。

R2b の検証はトレース保存・正値性と解析解との一致を中心にする。回復については R2c で参照系を用いた検証を追加する。既存回帰はリポジトリの通常 CI を用い、テスト件数の増加を科学的な前進の尺度にしない。

### 事前に予想する結論（未検証）

- 理想的な記録は、E への書込みの有無にかかわらず二つの観測者に同じ Z 情報を与える。一方、読出しの前後で SF1F2 が変わるかどうかは、その範囲に残るコヒーレンスに依存すると予想する。
- E まで記録した後に E を捨てると、SF1F2 は Z 情報を保持するが、任意入力の位相を完全回復する情報を失うと予想する。全体系への逆ユニタリは、読出し前なら回復の対照になる。
- 二つの記録があるだけでは、指定雑音に対する長期安定性や、単一結果の現実化は保証されない。

これらが予想どおりなら、既知の再現として成功とする。予想外の数値は直ちに発見と呼ばず、添字順序、部分トレース、読出し装置、回復条件を先に確認する。

### 全体履歴への接続

R2d では、R2b の閉じた4量子ビット基準回路だけを、4事象の開いた履歴へ書き直す。各事象のユニタリ積を V_j として `J|ψ⟩ = (1/2) Σ_{j=0}^3 |j⟩ V_j(|ψ⟩⊗|000⟩)` を用い、隣接事象の伝播制約と条件付き読出しを解析で確認する。

これは R1 系列で得た「全体履歴と内部変化の両立」を、新しい記録指標へ接続する作業である。一般的な decoherent histories の条件を満たす証明でも、異なる時計間の装置クラス閉性の証明でもない。R2c の雑音チャネルを同じ閉じたユニタリ履歴と呼ぶには環境への拡張が必要なので、その追加構成は今回の必須成果にしない。

## 6. 成功・中止・後続研究の条件

**理解としての成功:** 読出し結果が同じでも、評価する状態の範囲やアクセス条件によって、擾乱と回復可能性が異なることを、同一の小モデルの式・数値・説明で追える。記録の共有、指定雑音への保持、可逆性、存在論的現実化を別々に説明できる。

**中止・縮小条件:** 次のいずれかならその拡張を止め、得た区別を総括する。

- 既存台帳の言い換えだけになり、新しい比較や誤解の解消を一つも示せない。
- 結論のために無断でアクセス範囲・準備・操作クラスを変える必要がある。
- 参照系込み5量子ビットと指定比較を超える探索が必要になる。
- 回復の上限など必要な主張の根拠が確立できない。確認できた達成値まで縮小し、一般的不能を断言しない。
- 新しい物理法則や存在論を主張する根拠が「全体を記述できる」「記録がある」だけである。

**新規研究へ進む条件:** R2d 後に、文献と既存実装では答えが出ていない問いを一つ、固定した操作・入力・指標の下で書ける場合だけ、別の研究プロトコルへ進む。候補は「同じ記録統計の下で、物理的に実装できる操作制限からどこまで回復可能性を判定できるか」だが、現時点では新規性も実装妥当性も未確立である。

存在論的 becoming を扱う後続案には、採用する橋渡し仮定と、既存の全体履歴記述に対して何が異なる予測または説明条件になるのかを要求する。未解決問が残らなければ、R2 を理解・再現の完了として閉じる。新規性がないことを理由に無期限にモデルを増やさない。

## 7. リポジトリでの進め方と次の一手

本計画を PR #19 後の独立した計画 PR とする。実施を始めるときは **R2a：定義・既存成果の対応付け**から入り、その仕様に基づいて R2b の最小再現へ進む。R2b の式・コード・結果が一つの研究単位として整った時点を次のマージ候補とし、保持・回復比較と総括は後続 PR に分けられる。
