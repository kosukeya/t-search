## 1. 今回固定した範囲

基準は [R0](t_search_redesign_protocol.md)、[Stage 7C](stage7c_notes.md)、[Stage 7D](stage7d_notes.md)。既存の `A/B/C/M`、運動学的次元54、物理次元14、forward 制約を主対象とする。時計は A/C、B は対象、M は記録。no-record 制約は漏れ診断の対照にだけ使用し、同じ実験とは呼ばない。

最初の必要条件として、`e0` の操作を恒等に固定し、`e1` の「恒等 / M の Z 読み出し」を監査する。二事象への任意操作、B 制御、feedforward、リセットは未採用。数値は complex128、絶対許容誤差 `1e-10`。全14次元に対する演算子ノルムと196個の行列単位を使用し、例示入力は既存の `canonical_physical_history_state("forward")` 一つに固定した。探索次元・深さは増やさない。

装置候補の有限予算は、M にだけ結合する読み出しポインタ N 一量子ビット、初期状態 `|0>`、一回の `CNOT(M→N)` と N の Z 読み出し、結果一古典ビット、追加の再初期化・廃棄・feedforward なし、と固定する。N は既存 M と別で、実装する場合の運動学的次元は108になる。A の既存三つの読みをトリガ候補とし、C は参照時計とする。**この予算は運動学的装置の仕様であって、制約と両立する実装を認定したものではない。** 今回の54次元計算は、この装置から誘導される裸の Kraus 操作を既存物理空間へ直接作用させる近道を監査している。

## 3. 実装診断

再現コード: [r1_intervention_preflight.py](../experiments/r1_intervention_preflight.py)。全数値とソースハッシュ: [JSON](../results/r1_intervention_preflight.json)。以下は既存関数を利用した有限線形代数の監査である。

### 3.1 裸の M 読み出しは固定した物理空間を保たない

`J=history_physical_basis("forward")`、`P=JJ†` とする。裸の結果演算子は `K_m=I_ABC⊗|m><m|_M`。各結果について必要な支持条件は `(I-P)K_m J=0` である。

| 操作 | forward の漏れのスペクトルノルム | no-record の同ノルム |
| --- | ---: | ---: |
| 恒等、M の X | < 8e-16 | < 8e-16 |
| M の Y、Z | 0.9428090416 | < 8e-16 |
| M の Z 測定の各結果 P0、P1 | 0.4714045208 | < 8e-16 |

この差は丸め誤差でも、C 時計の誤計量でもない。54次元の正規直交な運動学的空間で測っている。

`J†K_mJ` と射影して戻すと、二結果の和は TP にならない。標準入力で残る確率は `7/9 ≈ 0.777778`、最大失敗確率は `4/9 ≈ 0.444444`。再正規化は失敗を隠すので採用しない。

代数的にも確認できる。記録対象 `Q=1` の部分では、W の三時点の記憶作用は `I,X,X`。自由な位相は記憶作用と可換で、scrambler は M に作用しない。裸の記憶演算子 k が一つの履歴を再び同じ履歴空間へ写すには `k=XkX` が必要で、十分でもある。したがってこの限定された **M のみの支持保存演算子代数は span{I,X}**。Z 読み出しの各 Kraus 演算子は属さない。Q=1 部分で圧縮された測定演算子は `(I±Z/3)/2`（結果の対応で符号が入れ替わる）となり、二結果の和の欠損は `4I/9`。Q=0 部分の欠損は0で、標準入力の Q=1 重み1/2から失敗 `2/9` を得る。

これは「どんな拡大系を使っても M を測定できない」という定理ではない。固定制約へ裸の操作をそのまま作用させる方法に限った除外である。X が支持を保つことも、X を特定事象で実行する装置の証明ではない。

### 3.2 物理的持ち上げは有効な測定だが、動的介入の証明ではない

Stage 7D の `physical_memory_projector(m)` は物理座標で直交射影になり、二結果の和は TP。残差は `4.82e-16`。標準入力の結果確率は `(1/2,1/2)`。

R_X を物理座標から時計 X の支持座標への可逆写像とし、`G_X=R_X^{-†}R_X^{-1}` とする。状態行列を `D_X=R_X ρ R_X†`、Kraus 演算子を `K_X=R_X K R_X^{-1}` と表せば、

`Σ K_X† G_X K_X = G_X`,

`Tr(G_X K_X D_X K_X†) = Tr(K ρ K†)`。

これは可逆座標変換の代数的帰結である。CP は物理内積を持つヒルベルト空間の間で保存され、逐次合成も中間の逆写像が相殺する。一般の介入列の共変性はこの条件の下で従うが、時計依存の装置制約の閉性は従わない。

今回の数値検算は A/C の各3読み、2結果、全196行列単位。最大分岐共変性残差は `2.95e-16`。これは同じ物理的操作の六つの座標表示であり、「同じ数値の時計読みが同じ測定事象」という認定ではない。

物理状態へのこの非選択測定を一つの新しい履歴として A/e0 へ還元すると、標準入力の**以前の完全な支持状態**とのトレース距離は `1/2` になる。これは測定による履歴の更新を示す。過去への信号や逆因果の証拠ではなく、過去の一部の観測確率を変更したという主張でもない。

より一般に、同じ固定制約の物理状態上の写像 Φ と、可逆な以前の還元 R0 に対して、全入力で `R0 Φ(ρ) R0† = R0 ρ R0†` を要求すると、左右から逆写像を掛けて `Φ(ρ)=ρ` となる。**完全な以前の状態を全入力で固定する限り、非自明な「後だけの変更」は同じ解空間上の写像では表せない。** この初等的観察は、部分系だけの過去周辺分布を保つ操作、条件付き更新、異なる制約族の比較を除外しない。新しい因果性の no-go 定理としては扱わない。

## 5. 再現・検証の範囲

通常のリポジトリ環境では次で監査を再実行できる。

```bash
python -m pip install -e '.[dev]'
python experiments/r1_intervention_preflight.py
python -m pytest -q tests/test_stage7c_relational_history.py tests/test_stage7c_anchor_semantics.py tests/test_stage7d_record_transport.py tests/test_r1_intervention_preflight.py
```

今回のローカル環境は Python 3.12.13・NumPy 2.3.5 を使用。networkx / pytest が利用できず、依存導入も完了できなかったため、数値モジュールを package path から直接ロードし、依存のある `t_search/__init__.py` を実行しない形で監査を走らせた。ソース関数の置換・変更は行っていない。監査の全 assert と、既存 Stage 7C の2ファイルの16テスト関数は成功。これは通常のパッケージ import や全リポジトリ回帰の検証ではない。通常 import の検証は PR の GitHub Actions が担当する。

結果 JSON は標準入力の診断と演算子レベルの検算を分け、使用する既存数値ソースの SHA-256 を保存している。数値残差の最下位桁は実行環境に依存する。CI の通過も `pilot_gate = blocked` を解除しない。
