# R1b — 読み出し装置を含む有限制約族の設計監査

日付: 2026-09-05。基準: [R1](t_search_r1_preflight.md)、commit `4b46b54cf180c627c3a972a6b4a434afa0180ad1`、PR #19。

**R1b は完了。固定した「三事象の閉じた周期・ポインタ一量子ビット・一周期一回のコピー・共通の準備」の候補は不採用。`pilot_gate = blocked` を維持する。** 制約族を具体化した結果、標準入力が周期境界を満たさないことを代数的・数値的に確認した。境界でコピーを逆に戻せば整合する対照モデルも構成したが、それは二回のポインタ相互作用を要し、R1 の予算外である。

今回は仕様不足を、**どの条件が両立しないかを示す限定された除外結果**へ進めた。一般の有限時計による測定の不可能性、RQ2 の時計間閉性への反例、新しい物理法則は主張しない。既知の周期履歴の整合条件を既存 Stage 7 の装置候補へ適用した設計監査・再現成果とする。

## 1. 対象と操作予算

既存の A/B/C/M にポインタ N を追加する。次元は `3×3×3×2×2=108`。A の三つの直交時計状態を `e0,e1,e2` とし、`e2→e0` も含む一周期を検査する。C は別の参照時計。追加の周回カウンタ、環境、再初期化、feedforward は導入しない。

入力は、A/e0 で既存の14次元 B/C/M 支持空間上の任意の密度演算子 ρ と `|0><0|_N`。特に既存の標準入力を含め、操作設定によって準備を変えない。N は M を制御とする一回の CNOT で読み出し、最終的に A/e2 に対応する N の Z 結果を問う。Z 読み出し自体は N=1 を0へ戻す操作ではない。

`e0→e1` の既存記録形成の**後**に M→N をコピーする順序を明示する。三事象の時計がこの二つの小操作の時刻を別々に分解できるとは仮定せず、一つの辺の内部順序として仕様化する。`e1→e2` の scrambler と、既存の `e2→e0` 復帰を固定する。

| 設定 | コピー辺 e0→e1 | 中間辺 e1→e2 | 閉じる辺 e2→e0 | 位置づけ |
| --- | --- | --- | --- | --- |
| off | 既存のまま | 既存のまま | 既存のまま | 正式な「読み出しなし」設定 |
| single | 既存の後に CNOT | 既存のまま | 既存のまま | 正式な「読み出しあり」候補。追加の N 操作は一回 |
| compensated | single と同じ | 既存のまま | 既存復帰の前に逆 CNOT | **予算外の診断対照**。結果を見て正式予算へ採用しない |

数値条件は complex128、絶対許容誤差 `1e-10`。探索する時計数・次元・制御深さを増やさない。下記の三設定の行列と、全入力についての演算子恒等式を検査する。

## 2. 明示的な有限制約族

Stage 7C の支持座標における還元から、`T_jk=R_A(j)R_A(k)†` を得る。これは14次元ユニタリで、`T_02 T_21 T_10=I`。以下では N 上の恒等とのテンソル積も T と略記し、28次元で計算する。`D=I_BC⊗CNOT_MN` と置く。

二設定 `s=0,1` に対して辺を

`U0(s)=D^s T_10`, `U1(s)=T_21`, `U2(s)=T_02`

とする。変更するのはコピー辺の結合だけであり、装置は M/N に作用する。S を28次元支持空間から36次元 B/C/M/N 空間への等長埋め込みとすると、108次元の制約は

`A_j = <t_(j+1)|⊗S† − <t_j|⊗U_j S†`,

`H(s) = (1/2)Σ_j A_j†A_j + I_A⊗(I−SS†)`。

添字は mod 3。第二項で既存の B/C 支持空間外を明示的に除く。H は半正定値で、零空間が各辺の条件付き遷移と周期境界を同時に満たす。内部事象は H の時計辺に含まれ、Python の実行順序だけで与えない。

これは**離散的な履歴伝播制約**である。off の零空間は既存 `H_hist⊗I_N` と一致するが、零以外のスペクトルを保存した変更ではない。理想的な連続時計の相互作用ハミルトニアンを離散化したもの、または固有の自律的連続時間装置とは認定しない。

`F0=I`, `F1=U0`, `F2=U1U0`, `L=U2U1U0` とする。L の固有値1の空間への等長写像 Q を選べば、物理基底は

`J=(1/√3)Σ_j |t_j>⊗S F_j Q`。

`HJ=0`、`J†J=I`、零空間の次元は `dim ker(L−I)`。これは三つの辺の条件を順に代入すれば導ける。既知の周期履歴の整合条件と同じで、[Churilov, Corollary III.3](https://arxiv.org/html/2608.05748v1)にも記載されている。同論文は2026年プレプリントであり、本監査ではこの等式を独立に導出・検算した。

## 3. 一回だけのコピーが失敗する理由

D は既存の中間辺 T_21 と可換なので、single の一周の作用は

`L_single = T_10† D T_10`。

N=0 の共通準備で周期条件が成立するのは、コピー時点の M が0である入力だけである。M=1 成分では N が1へ変わり、それ以降の辺は N に作用しないため、N=0 の開始状態には戻らない。

この説明は純粋状態の一例に依存しない。M の二つの射影を P0/P1 とすると、コピーは `P0|ψ>⊗|0> + P1|ψ>⊗|1>` を作る。その後 N と結合しない操作は N=1 の確率を変えられない。始点と終点で N=0 を要求すれば `Tr(P1ρ)=0` が必要になる。最終 Z 測定の非選択実施でも、この確率は変わらない。

| 設定 | 物理空間の次元 | N=0 で周期条件を満たす入力の次元 | 標準入力の一周の不一致ノルム |
| --- | ---: | ---: | ---: |
| off | 28 | 14 | 1.71e-15 |
| single | 21 | 7 | **1** |
| compensated | 28 | 14 | 1.65e-15 |

CNOT の固有値+1の次元は各 B/C 支持ペアについて3なので、single の物理次元は `7×3=21`。N=0 という準備も課すと M=0 の一成分だけが残り、入力次元は7。標準入力はコピー時点で M=1 の確率が1/2で、一周の不一致ノルムは `√(2×1/2)=1` となる。

single の許された7次元入力では N の結果は常に0。したがって入力をこの空間へ制限すれば形式上の二設定比較はできるが、元の任意入力や情報を持つ読み出し課題を失う。これを解決策に採用しない。標準入力の single に対する結果確率は**未定義**とし、射影・再正規化して数値を作らない。

## 4. 境界の逆操作を明記した対照

compensated では `U2=T_02 D†` とする。これなら一周は恒等になり、任意の14次元入力と N=0 を保持できる。CNOT は自己逆だが、コピー辺と境界でそれぞれ一回必要で、相互作用回数は**一周期二回**である。

対応する dressing は、A/e0 で恒等、A/e1,e2 で D を作用させる時計依存ユニタリ W。`W(H_hist⊗I_N)W†` の零空間は compensated と一致する。したがって、単純に W を書き換える方法も、辺まで展開すると**閉じる辺の逆操作を含む**。これは無料の境界処理や記号の変更ではない。

二つの coherent history は A/e0 で同じ準備を持つ。A/e2 の N 測定が B/C/M 上に誘導する Kraus 演算子は

`K_n = T_21 P_M,n T_10`, `Σ_n K_n†K_n=I`。

これを108次元の装置から縮約して確認した。TP 残差は `6.85e-15`、上の解析式との残差は `1.12e-16` 未満。標準入力では off の N 分布は `(1,0)`、compensated は `(1/2,1/2)`。compensated の最終 B ビットと N の同時分布は四成分とも1/4。これは既存の scrambler による相関構造と整合する。

逆操作は N の量子情報を戻す coherent な操作で、記録の永久保存や不可逆なリセットではない。もし途中で結果を別の古典記録へ保存し、その記録も含めて何周も閉じた実験を要求するなら、その記録媒体と境界処理もモデルに含める必要がある。今回の対照は、その反復測定装置まで実装したものではない。

## 5. A/C の時計還元と「同じ出来事」の照合

各制約の J から `D_X(j)=√3(<t_j|_X⊗I)` を還元し、QR 分解 `D_X(j)J=Q_XR_X` により支持空間・座標を導き直す。A/C の全3読みで階数はそれぞれの物理次元と一致する。最小特異値は A で約1、C で約0.428373。逆写像は全設定で存在する。

誘導計量は `G_X=R_X^{-†}R_X^{-1}`。観測事象は**A/e2 のポインタ結果**として装置モデルで固定する。物理座標の効果

`E_n = Q† F2† (I⊗|n><n|_N) F2 Q`

を `R_X E_n R_X^{-1}` と輸送して、各 C 読みの座標でも同じ事象を問う。計量・逆写像・全入力の確率保存の演算子恒等式の最大残差は `3.03e-14`。off と compensated の標準入力の全結果確率も、A/C の六つの座標で一致する。single は標準入力を持たないので、この比較をしない。

一方、compensated に対し**裸の N を C=j で条件付ける別の質問**では、N=1 の確率が `(3/14,3/7,3/8)` になる。A/e2 の1/2と比較して不整合と呼ばない。同じ整数の時計読みは同じ装置事象を意味せず、C の一つの鋭い読みが A/e2 だけを選び出すわけではない。

single の21次元全物理空間では、E_n は一般に射影ではなく POVM 効果になる。確率の共変性は検算でき、`sqrt(E_n)` により数学的な instrument も作れるが、それを周期内の局所検出器として実装したとは扱わない。これは R1 で確認した「有効な物理観測量」と「時間指定の装置」の区別を保つためである。

## 6. 文献との対応と新規性

| 再現基準 | 今回の対応と限界 |
| --- | --- |
| [Hausmann et al., 2025, §5・Appendix G](https://arxiv.org/html/2308.10967v4) | 離散的な時計辺に測定相互作用を埋める方法を参照。主例の整数ラベル列を有限三周期へ閉じると、追加の一周条件が必要になる。同じ定理の無条件適用とはしない。 |

| [Churilov, 2026, §III](https://arxiv.org/html/2608.05748v1) | 周期履歴の零空間と一周の不動点の対応を独立に確認。今回の21/7次元という値は Stage 7 への適用結果で、一般原理の新発見ではない。 |

「一回コピーした情報は、何もしなければ周期の始点で消えない」という境界の障害は既知のユニタリ性と周期整合性から従う。今回の価値は、t-search の候補に隠れていた追加操作と入力制限を具体的に露出させたことにある。時計変更と独立な I_A/I_C の非自明な閉性命題は得ていない。

## 7. 判定・終了条件

`R1b_status = completed_strict_candidate_rejected` / `pilot_gate = blocked` / `RQ2_closure = not_tested` / `novelty = not_established`。

正式な off/single 制約族は構成できたが、同じ任意入力の準備を共有できない。compensated は coherent な装置と時計還元の再現対照として成立するが、予算を超える。このため [R0](t_search_redesign_protocol.md)の「装置・資源条件を満たせない場合は記録して停止」に従い、**現在の三周期・単一コピー候補はここで終了する**。Stage 17 や大きな次元の探索へ移らない。

今後続ける場合は、研究目的を先に選び直す必要がある。例えば境界での逆操作を正式資源に含めた一周期の再現課題、または周期条件自体を変更する装置モデルは別の仕様になる。どちらも今回の予算の例外として自動採用しない。新規性のない再現課題を完了したところで研究を終える選択も保持する。新しい R1c や R2 を自動選定しない。
