## 1. 監査結論

**R2b は、既知の量子情報の区別を再現する小さな研究として実装可能である。** 新しく整理する焦点は「同じ読出し統計でも、共同状態に残るコヒーレンスと読出し擾乱は異なり得る」。単に可逆な記録を作ること、記録へ雑音を加えることは、既存成果との重複が大きい。

今回固定した重要な区別は以下の三つ。

1. **一致と情報:** 常に同じ固定値を返す二つの媒体も一致する。対象の値を正しく区別できるかを別に測る。
2. **無信号性と共同状態の非擾乱:** 記録上の非選択操作が S 単体を変えないことだけでは不十分。SF1F2 および SF1F2E の前後を比較する。
3. **状態の範囲:** 二つの局所的な SFk が古典的でも、SF1F2 全体に量子コヒーレンスが残る場合がある。どの状態について SBS や非擾乱を判定したかを省略しない。

判定は R2a completed、R2b specification ready、R2b/R2c/R2d unstarted、novelty unestablished。元の pilot_gate = blocked、周期単一コピー候補の不採用、Stage 17 の凍結を維持する。

SBS は本書では固定 Z 基底について

$$
\rho_{SF_1F_2}=\sum_{b=0}^1p_b|b\rangle\langle b|
\otimes\tau_b^{(1)}\otimes\tau_b^{(2)},\qquad
\tau_0^{(k)}\tau_1^{(k)}=0
$$

という**状態構造**を指す。一般の量子状態のコピー、単一結果の現実化、宇宙の存在論とは区別する。Z は装置設計により固定しており、選好基底を創発させる研究ではない。

| 共有された記録 | 別々の Fi から同じ対象変数を読めること。独立なアクセスは結果が統計的に独立であるという意味ではない |

## 4. 凍結する回路・入力・状態の範囲

本体の因子順は **G = S ⊗ F1 ⊗ F2 ⊗ E**。計算基底の添字は \(8s+4f_1+2f_2+e\)。任意入力は

$$
\rho=\begin{pmatrix}a&c\\c^*&1-a\end{pmatrix},
\quad 0\leq a\leq1,\quad |c|^2\leq a(1-a),
\qquad \rho_{\rm in}=\rho\otimes|000\rangle\langle000|.
$$

\(C_1,C_2,C_E\) はそれぞれ S を制御として F1、F2、E を反転する CNOT。右から順に作用する。

| 条件ID | 総ユニタリ U | 等長写像 \(V:b\mapsto g_b\) |
| --- | --- | --- |
| no_record | \(I_{16}\) | \(|b\rangle\mapsto|b000\rangle\) |
| records_E_off | \(C_2C_1\) | \(|b\rangle\mapsto|bbb0\rangle\) |
| records_E_on | \(C_EC_2C_1\) | \(|b\rangle\mapsto|bbbb\rangle\) |

全体出力は \(\Omega=V\rho V^\dagger\)、評価する共同状態は \(Q=SF1F2\)、\(\omega_Q=\operatorname{Tr}_E\Omega\)。Q という文字は評価範囲の略記であり、Stage 7 の対象射影 Q を意味しない。

入力用途を分ける。

- **校正入力:** 古典ラベル \(B\in\{0,1\}\) を等確率で選び \(|B\rangle\) を準備する。誤り率はこのラベルと照合する。B を装置や回復器に渡さない。
- **擾乱入力:** 任意の \(\rho\) の解析式を基準に、数値では \(|0\rangle,|1\rangle,|+\rangle,|+i\rangle,I/2\) と、\(a=1/3,c=(1+i)/6\) の6状態だけを使う。
- **回復入力（R2c）:** 操作しない参照 R と S の \(|\Phi^+\rangle=(|00\rangle+|11\rangle)/\sqrt2\)。因子順は R,S,F1,F2,E。

校正アンサンブルを平均した \(I/2\) だけで擾乱を判定すると、元から \(c=0\) のため重要な差が消える。コヒーレントな入力の診断を必須にする。

## 5. 読出し装置と評価する操作

Fi の Z 基底射影を、G 上に恒等作用を補って \(P_b^{(i)}\) と書く。結果付き装置は

$$
\mathcal I_b^{(i)}(\Omega)=P_b^{(i)}\Omega P_b^{(i)},\qquad
\mathcal M_i=\mathcal I_0^{(i)}+\mathcal I_1^{(i)} .
$$

各分枝は CP・トレース非増加、和は TP。分枝確率はそのトレースで、確率0の条件付き状態は未定義として出力しない。正の確率の条件付き状態と確率を組にして保持し、全分枝を再合成できるようにする。これは条件付き状態の定義であり、不都合な結果を捨てるポストセレクションではない。

読出し集合は \(K=\{1\},\{2\},\{1,2\}\)。別因子の射影は可換なので \(\mathcal M_{12}=\mathcal M_2\mathcal M_1=\mathcal M_1\mathcal M_2\)。二つの読出しの順序による差を新規の時間効果として作らない。同じ Fi の直後の再読出しは射影の冪等性から同じ結果になるが、それだけでは情報性や保持を保証しない。

Fi の読み出し窓口だけを各観測者へ与える。S を直接読む操作や、Q 全体を制御する操作は共有の精度を上げるためには使わない。Q と G の状態距離は理論的な比較量であり、Fi しか読めない観測者がその距離を直接測定できるという意味ではない。

R2b ではこの標準的な射影装置を明示した操作として採用する。読出しの追加媒体を含む閉じた制約族を構成したとはしない。したがって R1b の時間指定装置の問題を解いたとも主張しない。

## 6. R2b の指標と解析的な検算基準

### 6.1 正確さ・共有

校正実験の共同分布を

$$
p(b,x,y)=\tfrac12\operatorname{Tr}
[P_x^{(1)}P_y^{(2)}V|b\rangle\langle b|V^\dagger]
$$

とする。誤り率は \(e_1=\sum p(b,x,y)[x\ne b]\)、\(e_2=\sum p(b,x,y)[y\ne b]\)。一致率は \(A=\sum p(b,x,y)[x=y]\)。同じ入力で二人が同時に正しい確率も分布から再計算可能にする。

### 6.2 擾乱

非選択の前後について

$$
D_X^{(K)}=\tfrac12\left\|
\operatorname{Tr}_{G\setminus X}\{\mathcal M_K(\Omega)-\Omega\}
\right\|_1,\qquad X=S,Q,G
$$

と定義する。トレースノルムを Frobenius ノルムで代用しない。\(D_S=0\) はすべての条件で成立し、無信号性の対照であって記録の品質判定ではない。

以下は**仕様で解析的に導出した検算値**であり、R2b の実行結果ではない。擾乱はどの非空 K でも同じ値。

| 条件 | \(e_1,e_2\)（校正入力） | 一致率 A | \(D_S\) | \(D_Q\) | \(D_G\) |
| --- | --- | --- | --- | --- | --- |
| no_record | \(1/2,1/2\) | 1 | 0 | 0 | 0 |
| records_E_off | \(0,0\) | 1 | 0 | \(|c|\) | \(|c|\) |
| records_E_on | \(0,0\) | 1 | 0 | 0 | \(|c|\) |

**導出:** \(q_b=|bbb\rangle\) とすると、E_off では
\(\omega_Q=a|q_0\rangle\langle q_0|+(1-a)|q_1\rangle\langle q_1|+c|q_0\rangle\langle q_1|+c^*|q_1\rangle\langle q_0|\)。
読出しは後ろの2項だけを消す。差の非零固有値が \(\pm|c|\) なので距離は \(|c|\)。E_on では \(\langle0|1\rangle_E=0\) により部分トレース時点でその2項が消える。一方、G 上では2項が残る。no_record では Fi が固定0なので何も変わらない。

\(|+\rangle\) 入力なら E_off の \((D_Q,D_G)=(1/2,1/2)\)、E_on は \((0,1/2)\)。E_on の Q は固定 Z 基底の SBS 形だが、G は \(c\ne0\) ならその SBS 形ではない。E_off の Q も \(c\ne0\) なら SBS 形ではなく、\(c=0\) なら SBS 形になる。

E_off でも各 SFk の状態は既に対角的で、\(|+\rangle\) 入力について各断片の量子相互情報量・Z アンサンブルの Holevo量・そのアクセス可能情報は1 bitになる。これは Q 全体の SBS を保証しない。**断片単独の条件を全体の条件へ昇格させない。** 本書はこの例を L2/L3 の全仮定を満たす反例とは呼ばない。

SBS の確認は指定 Z 基底について、S の異なるブロック間の成分が0、各正確率ブロックが Fi の条件付き状態の積、各断片で b=0/1 の支持が直交、という三条件を直接確認する。一般の全基底最適化や最も近い SBS への距離を計算したとはしない。確率0の枝は状態単体の構造判定では除くが、「情報を記録できる装置」の校正には両方の入力を使う。

## 7. R2b の実装・検証仕様

実装は NumPy の密度行列と明示的な CNOT・Kraus 演算子で足りる。新規依存は不要。既存の qutrit 制約用関数を改造せず、4量子ビットの積空間を明示する。共有する価値のある既存汎用関数がなければ、小さな専用関数に留める。

予定成果物は experiments/r2_shared_records.py、results/r2_shared_records.json、tests/test_r2_shared_records.py。必要なら数学関数だけ src/t_search/r2_shared_records.py に分ける。実行入口は experiments のスクリプト、検証入口は通常の pytest とする。

結果 JSON に必須の内容:

- 仕様版 r2a-v1、条件ID、因子順、装置、入力、許容誤差、実行時のコード版を記録する。
- 校正用 \(p(b,x,y)\)、誤り率、一致率を保存する。
- 6入力×3条件について、各非空 K の \(D_S,D_Q,D_G\) と解析値との差を保存する。
- 分枝確率、CP/TP の構成根拠と数値残差、状態のトレース・Hermitian性・最小固有値を記録する。
- 固定 Z の SBS 構造検査を Q と G で区別する。未定義な条件付き状態は null と理由を保存する。
- 解釈は known-result reproduction とし、objectivity や becoming の包括的な成功フラグは作らない。

検証で解消する具体的なリスク:

| リスク | 必須の照合 |
| --- | --- |
| 添字・制御標的の取り違え | 明示的な基底写像と回路出力を比較する |
| 複素共役・部分トレースの誤り | 任意 \(\rho\) の上記解析式、特に \(|+i\rangle\) と非対称混合入力で比較する |
| 正値性を CP と取り違える | 読出しの Kraus 構成と完備性、等長写像の \(V^\dagger V=I_2\) を確認する。有限入力の正値性検査だけで CP を宣言しない |
| 不都合な分枝の除外 | 全分枝の確率が1、非選択出力へ再合成できることを確認する |
| 共同状態の範囲の混同 | E_on の Q と G の距離が異なり、S 単体は全条件で不変となることを確認する |
| 実装の自己確認だけになる | 解析式・基底写像から得た期待値と独立に照合する。比較演算子の順序と再読出しの冪等性も確認する |

行列等式の残差は Frobenius ノルム、状態距離はトレースノルムとして名前を分ける。数値許容誤差は絶対値 \(10^{-10}\)、相対許容誤差0。これは理想的な式を検算する丸め許容幅で、実験装置の許容誤り率ではない。トレースの強制再正規化や負固有値の無条件クリップで失敗を隠さない。

R2b の完了には3条件の解析値との一致、上のリスクの検証、再現可能な結果、既存回帰の確認を要求する。入力や次元を増やすことは完了条件ではない。

## 8. R2c/R2d へ引き継ぐ定義（実施は後続）

**保持:** Fi に独立な \(\mathcal B_p(\rho)=(1-p)\rho+pX\rho X\) を一回、読出し前に適用。\(p=0,0.1,0.25,0.5\) に限定する。記録ありの校正では \(e_k=p\)、\(A=(1-p)^2+p^2\)、両方正しい確率は \((1-p)^2\)。no_record は誤り率1/2のままで、雑音を同じように適用すると一致率は同じ A になる。これらは二元対称雑音からの検算式であり、新規性を主張しない。

**回復:** 雑音も読出しもない符号化直後を出発点にし、\(\mathcal N_X=\operatorname{Tr}_{G\setminus X}\circ V(\cdot)V^\dagger\)、回復器 \(\mathcal R_X:X\to S'\) を決定論的 CPTP とする。\(X=Q,G\) は別の資源集合。R や入力ラベルにはアクセスせず、初期入力から独立な補助系だけを許す。

$$
F_e=\langle\Phi^+|
(\operatorname{id}_R\otimes\mathcal R_X\mathcal N_X)
(|\Phi^+\rangle\langle\Phi^+|)
|\Phi^+\rangle .
$$

平方根を取らない fidelity の規約を採用する。これは任意入力を扱うチャネルの基準であり、既知の \(|+\rangle\) を再準備するテストではない。

検算基準は no_record の Q/G と E_off の Q/G、E_on の G で最適 \(F_e=1\)。E_on の Q では最適 \(F_e=1/2\)。

**後者の上限の根拠:** \(\mathcal N_Q(\rho)=\sum_b\rho_{bb}|bbb\rangle\langle bbb|\) は測定・再準備型（L7）。任意の回復後の RS′ は \(\tfrac12\sum_b|b\rangle\langle b|\otimes\sigma_b\) であり、
\(F_e=\tfrac14\sum_b\langle b|\sigma_b|b\rangle\leq1/2\)。
\(\sigma_b=|b\rangle\langle b|\) にするデコーダで達成する。他の条件はアクセスできる範囲で符号化を逆転して達成する。一般入力の異なる位相が同じ \(\mathcal N_Q\) 出力へ潰れることも、完全回復不能の別の説明になる。

これはこの符号化・アクセス集合についての既知の構造からの解析であり、R2c の数値結果や一般的な物理不可逆性の証明ではない。二つのアクセス集合は資源が異なるため、同じ資源予算での時計変更の比較（元の RQ2）ではない。

**履歴:** R2d では基準回路を開いた4事象の制約履歴へ接続する。ここで与えた相互作用順序や純粋な装置準備から時間の矢が創発したとはしない。雑音・読出しを含む閉じた全装置の履歴構成は、本書の基準回路の証明と区別する。
