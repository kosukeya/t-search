# R2b — 共有と読出し擾乱の最小再現

2026-09-06。**R2b の実装・解析照合・新規テストを完了。** [R2a仕様](t_search_r2_records_spec.md) r2a-v1 に従った既知の結果の再現である。全体回帰の最新状況は [PR #20](https://github.com/kosukeya/t-search/pull/20) のチェックと検証欄に記録する。

## 結果の要点

**二人が正確に同じ記録を読めることと、その読出しが共同状態を乱さないことは、別々に評価する必要がある。** また、同じ読出しでも「共同状態」にどの部分系を含めるかによって擾乱の判定は変わる。

S、F1、F2、E の4量子ビットで、無記録、F1/F2への記録、F1/F2/Eへの記録を比較した。校正は等確率の Z 入力、擾乱は仕様で指定した6入力、読出しは F1・F2・両方の3通り。18ケース・54通りの読出し比較を行った。

以下の擾乱はコヒーレントな |+⟩ 入力、結果を平均した非選択 Z 読出しについてのトレース距離である。どの非空の読出し集合でも同じ値となった。表の 1/2 は浮動小数点表示の 0.4999999999999999 を解析値で表している。

| 条件 | 各観測者の校正正答率 | 二人の一致率 | Sだけの擾乱 | SF1F2の擾乱 | SF1F2E全体の擾乱 |
| --- | --- | --- | --- | --- | --- |
| 無記録 | 1/2 | 1 | 0 | 0 | 0 |
| F1/F2へ記録、Eへの書込みなし | 1 | 1 | 0 | 1/2 | 1/2 |
| F1/F2/Eへ記録 | 1 | 1 | 0 | 0 | 1/2 |

無記録の二つの媒体はいつも0を返すので一致するが、対象の0/1を区別できない。対象 S だけの不変性は無信号性によってすべての場合に成立し、それだけでは記録の質を判定できない。

Eへも記録した条件では、Eを部分トレースした SF1F2 は既に異なる記録値間のコヒーレンスを持たない。この共同状態の Z 記録は非選択読出しで変わらない。一方、Eを含む全体にはコヒーレンスが残り、同じ読出しによって失われる。

これは読出しによって一つの結果がどう現実化するかを説明したことにはならない。また、Fiだけを読める観測者が共同状態のトレース距離を直接測定できるとは仮定していない。

## 解析式との照合

入力を rho=[[a,c],[c*,1-a]] とすると、記録あり・Eへの書込みなしでは (D_Q,D_G)=(|c|,|c|)、Eへの書込みありでは (0,|c|)。無記録ではともに0。Sについては常に0である。仕様の式と数値結果の最大絶対差は **0.0** だった。これはこの演算と有限入力での数値的一致であり、浮動小数点計算が一般に厳密であるという主張ではない。

固定 Z 基底の SBS 構造も、状態の範囲ごとに検査した。|+⟩ 入力では、Eへの書込みありの Q=SF1F2 が SBS 形で、G=SF1F2E はその形ではなかった。Eへの書込みなしでは Q/G ともに不成立。I/2のような非コヒーレント入力では違う判定になるため、校正入力の平均だけで検査を済ませていない。

GのSBS検査では F1・F2・E のすべてを断片とする。そのため、Eへの書込みなしの場合は、コヒーレンスをなくしても、Eが対象の値を区別できないという別の理由でGのSBS条件を満たさない。正確率の枝が一つしかない入力では状態の構造条件が自明に成立するが、それを両方の入力を記録できる装置の証明として数えていない。

- [実験コード](../experiments/r2_shared_records.py)：NumPy の CNOT、等長符号化、部分トレース、結果付き射影装置、トレース距離、固定 Z の状態構造検査。
- [結果JSON](../results/r2_shared_records.json)：校正共同確率、全ケースの状態・分枝確率・条件付き状態、擾乱、構造診断、数値残差。

リポジトリの通常環境では以下で再現する。

```bash
python experiments/r2_shared_records.py

```

新規部分は標準 unittest でも実行できる。


ローカル実行は Python 3.12.13 / NumPy 2.3.5、14テスト成功。既存回帰に必要な依存がローカルでは揃わなかったため、通常の全リポジトリ pytest は GitHub Actions で確認する。新規テストは既存実験と同じ runpy 方式で実験ファイルを読み、パッケージのコードや既存テストは変更していない。

コード版はR2a基点コミットと実験・テストファイルのSHA-256で結果に記録した。JSONのPython/NumPyバージョンは生成環境を示す。CIではその文字列の一致を要求せず、科学的な内容を絶対誤差1e-10、相対誤差0で再生成結果と照合する。ソースのSHA-256は一致を要求する。

## 検証の範囲

- CNOTの全計算基底上の写像、等長性・ユニタリ性、Kraus完備性と各分枝の効果の上限を確認した。CPは明示的なKraus構成による。
- 複素入力と非対称混合入力を含め、符号化・部分トレース・読出し後の状態を独立な期待値と照合した。
- すべての分枝を確率付きで保存し、非選択状態へ再合成した。確率0だけを未定義状態としてnullで示し、微小な正確率の枝は捨てていない。
- 再読出しの結果の再現、非選択操作の冪等性、F1/F2の操作順序の一致を確認した。
- SBS診断には、条件付きの断片間相関と、記録の支持の重なりを別々に検出する対照を含めた。

最大トレース誤差は 2.220446049250313e-16、最小固有値は -4.930380657631326e-32。いずれも許容誤差内で、再正規化や固有値のクリップはしていない。等長性・ユニタリ性・TP完備性・分枝再合成・読出し順序の記録残差は0だった。

初回のテストでは、SBS不成立を示す非零残差まで一律に0と要求するテスト側の過剰な条件が1件失敗した。非零の構造診断と、0を要求する実装整合性残差を分離して修正した。科学的な期待値やモデルを変更したものではない。

## 研究上の意味と次の段階

Stage 3・7で扱った「局所的に読めることと全体構造は異なる」という区別を、二つの記録の共有と、共同状態の読出し擾乱へ具体化できた。文献との対応は [R2a §3](t_search_r2_records_spec.md) のとおりで、新しい量子法則や存在論的な識別結果を主張しない。

本実験は初期準備、Z基底、相互作用順序を与えている。長期保持、熱力学的な不可逆性、未知入力の回復、全体履歴への追加構成、単一結果の現実化、時間経験は今回の成果に含めない。

次は **R2c：保持と回復の切り分け**。指定された一回の記録雑音と、Q/Gというアクセス範囲による回復可能性を、別の比較として実施する。元の pilot_gate = blocked、周期候補の不採用、Stage 17 の凍結は維持する。
