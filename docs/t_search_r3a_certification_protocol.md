# R3a — 回復能力の認定条件：短いプロトコル

2026-09-06。版 `r3a-v1`。基点は [PR #20](https://github.com/kosukeya/t-search/pull/20) のマージ `64bc53871d2e16129f06e85acf79ec7dc29d2e9b`。**R3aの定義・既存研究監査を完了。R3bの数値再現は未実施。** [監査本文と解析](t_search_r3a_certification_audit.md)を伴う。

## 目的・質問

blockness／becomingへの理解を深めるため、「全体に情報がある」「許された操作で回復できる」「観測データから実行済みの回復性能を保証できる」を分ける。

**研究質問:** 信頼する準備・測定と許容する接続を明示したとき、Z/X二基底の検査から、実行した回復処理の未知入力に対する性能をどこまで保証できるか。

対象は入力Sから出力S′までの合成チャネル Λ=𝓡∘N_Q。N_Qは符号化後にEを部分トレースしたチャネル、Rは実行する回復器。特定の内部回路、全ての許容回復器の最適値、装置資源の物理的由来をデータだけから認定する問いにはしない。

## 固定する条件

| 項目 | `r3a-v1` の条件 |
| --- | --- |
| 本体 | R2のS,F1,F2,Eの4量子ビット。既存の無記録・E_off・E_onを維持 |
| 回復器の窓口 | Q=SF1F2のみ。E、参照R、検査ラベル、設定情報、入力を迂回して渡す経路へのアクセスなし |
| 基準回復器 | 無記録ではSの出力。記録ありではR2cの二つの書込みを逆転し、F1/F2を捨てる。同じ記録用回復器をE_off/E_onで使う |
| 検証者 | 信頼できる0,1,+,−の入力準備と、S′の対応するZ/X射影測定。検査ラベルを保存して集計するが、装置へ渡さない |
| 操作の扱い | ゲート名は実行要求を示す。未知の実現誤差を含むΛの性能が測定対象であり、ゲートが完全と仮定して性能を認定しない |
| 通信 | 検証者から装置への古典的なラベル・基底情報の漏れを禁止。基準回復器に適応制御は不要。別の回復器を使う場合は操作・通信を別途宣言する |
| 共通仮定 | 固定した入出力量子ビット空間、決定論的CPTP、条件ごとに同一の処理。試行間に装置をリセットし、検査設定に応じた装置切替をしない |
| 今回の精度 | 理想的な準備・測定と厳密なBorn確率。有限標本の信頼区間やSPAM誤差の補正は含めない |
| 規模・除外 | 本体4量子ビット、参照での真値検算のみ5量子ビット。雑音掃引、GST実装、回復器探索、物理時計・履歴装置の追加はしない |

これらは条件付き認定のための仮定であり、実機で独立に検証済みとはしない。準備・測定を信頼することと、回復器を完全と信頼することは異なる。

## 指標と既存研究との差分

F_Zは0/1入力の出力正答率の平均、F_Xは+/−入力の出力正答率の平均。R2の記録Fiの正答率とは測定対象が異なる。目標は恒等チャネルで、F_eはR2cと同じ正規化Bell参照との重なり（平方根なし）である。

$$
L=\max(0,F_Z+F_X-1)\le F_e(\Lambda)\le
U=\min(F_Z,F_X).
$$

これはHofmannの既存境界を適用したもの。正しく実装された独立な認定器には四つの出力正答確率と宣言した仮定だけを渡し、条件ID、回路行列、Choi状態、解析的な真値は渡さない。真値の計算は照合側へ分ける。

L>1/2なら、上記仮定の下で測定・再準備だけの合成チャネルを除外できる。L≤1/2は不能判定ではない。Uは実行したΛの上限であり、別の回復器を使った最適性能の上限ではない。最悪入力誤差、長期保存、存在論的生成へ言い換えない。

監査の結論は **信頼された準備・測定の下での性能保証は既存研究で答えられる**。差分はR2の回復・アクセスの議論へ保証の前提を対応付けたこと。一般的な認定法や新しい物理的原理の発見ではない。

## 成功・中止・後続条件

**R3aの成功条件（完了）:** 認定対象、役割別資源、既存定理の仮定、解析境界、認定できない内容、後続の検算方法を特定する。

**後続R3bを実施する場合の仕様:** 既存3条件×4検査入力の確率からL/Uを計算し、独立な参照付きF_eを含むことを照合する。Z位相反転、固定＋再準備、同じF_Z=F_X=3/4を持つ二つのPauliチャネルを論理チャネルの対照として加える。期待値は監査§4。認定器の入力分離、CP/TP、全分枝、複素位相、保存結果の再現性を検証する。既存回復実装を変更せず、追加依存・最適化器は不要。これは既知の保証と限界の一回の再現に限定する。

**中止・縮小条件:** 準備・測定の信頼を確立できない、設定漏れや入力の迂回がある、損失を選別している、真値や条件IDを認定器へ渡す、最適回復可能性や特定ゲートの実行を境界から主張する、という場合は保証を停止する。新規性のないことを理由にモデル・設定を増やさない。

次に実装へ進むなら **R3b：二基底検査による回復性能保証の最小再現**。本段階では未実施。短い再現で理解が増えるかを区切りとし、それを越える新規研究の問いは本監査では確立していない。元の `pilot_gate = blocked`、周期候補の不採用、Stage 17凍結を維持する。
