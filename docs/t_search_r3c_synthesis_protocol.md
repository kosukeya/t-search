# R3c — 認定の限界の切り分けとblockness／becomingへの総括

2026-09-07。版 `r3c-v1`。**本書はユーザーの依頼により今回定義した後続計画。R3cの監査・総括そのものは未実施。** 過去に合意済みだった計画を復元したものではない。基点はR3bの `e06fa27917bbc6e23f1ef6ccae940a045b920c60`（[PR #21](https://github.com/kosukeya/t-search/pull/21)、未マージ）。

## 1. 出発点と選定理由

目的は引き続き **blockness／becomingへの理解を深めること**。R3cは一回の解析監査と総括であり、新しい認定器や大規模実験を作る段階にはしない。

| 既存成果 | 確認できたこと | 未決定のこと |
| --- | --- | --- |
| [R2総括](t_search_r2_synthesis.md) | 有限モデルで、全体履歴表示・内部記録形成・アクセスによる回復限界が両立 | 未来の実在、単一結果の現実化、体験される時間 |
| [R3a監査](t_search_r3a_certification_audit.md) | 信頼条件の下で実行した合成チャネルの性能を保証できる。別実装の解析例もある | 準備・測定・配線の物理的妥当性、特定ゲートの同定 |
| [R3b](t_search_r3b_recovery_certificate.md) | 四つの正答確率だけを受け取る認定器で7条件・28設定を再現。真値の漏れ込みを防いだ | 二基底統計で定まらない忠実度、内部資源、存在論的解釈 |

R3b基点のPR/push CIはいずれも **1394テスト・18サブテスト成功**。これは実装検証であり、上表の未決定事項を解いた根拠ではない。結果JSONを更新せず、既存の証拠として使う。

現段階で優先するのは、認定が届かない理由を区別すること。「測定が足りない」「見る窓口が同じなら実装を区別できない」「検査自体の前提が必要」「存在論への橋渡しがない」を一つの『分からない』にまとめない。この区別がR3bの個別結果に対するR3cの追加価値である。

有限標本・校正誤差の研究は実験的な保証には有用だが、今の理解上の問いを総括する必須条件ではない。回復器の追加実装も、既存の解析で区別を示せる限り必須にしない。

## 2. 中心質問と固定した四つの確認課題

**中心質問:** 全体履歴、アクセスによる回復、測定からの性能保証を接続したとき、何がデータから決まり、何に別の操作・装置情報・解釈上の前提が必要になるか。

| 課題 | 用いる証拠と行う作業 | 必ず区別すること |
| --- | --- | --- |
| C1：検査の情報不足 | R3bのPauli A/Bを再読し、同じ四確率・異なる忠実度を確認。既知のPauli作用からY方向の正答率を紙上で比較する | Z/X検査での識別不能と、入出力検査一般での識別不能 |
| C2：合成チャネルと実装 | R3a §5の逆CNOT型とX測定・古典通信・Z補正型を解析照合。E_offの全入力への作用、全分枝のTP、必要な操作・通信を並べる | 性能が同じことと資源が同じこと。合成チャネルが同じ場合の入出力同定の限界 |
| C3：認定の信頼条件 | R3aの準備・測定・固定次元・同一処理・リセット・設定漏れ/迂回なし・選別なしを、誰が何で確かめる条件かへ対応付ける | 仮定を宣言することと、その妥当性を物理的に検証すること |
| C4：全体履歴への接続 | R2dの既存構成とR3の性能保証を主張台帳へ対応付ける | 全体記述の存在、内部での利用可能性、性能の認定、存在論的生成 |

C1のY比較は、固定された二つの既存Pauli対照を識別する解析に限定する。R3bの認定器を三基底版へ変更せず、一般のチャネルを完全再構成したとは言わない。新しい測定窓口で得られる情報と、その準備・測定を信頼する条件を併記する。

C2の等価性は、固定符号化と合成した **S→S′のチャネル**、全結果を平均した決定論的処理について確認する。Q全空間における回復器同士の同一性、アクセス可能な内部ログを含む装置の同一性、任意の途中介入に対する同一性へ拡張しない。同じ合成チャネルなら参照を含む入出力検査も一致するが、内部操作へのアクセスを追加すれば別の問題になる。

X測定・通信・補正型は、Sに量子情報を残して条件付き補正する回復である。Sを測定して捨て、出力を再準備するだけの合成チャネルとは異なる。R3aのL>1/2による測定・再準備型の除外と矛盾させない。

C3では、四つの確率だけで外部の信頼条件まで認定する循環を避ける。準備・測定を同時推定するGSTのゲージの問題と、C2の固定された入出力チャネルから内部実装を同定できない問題も別々に記す。

## 3. 許容操作・既存研究との差分

- 既存文書・コード・結果の読取り、既存式の解析照合、資源表・主張台帳・総括の作成を行う。
- R3bの7条件・28設定、認定器の入力、信頼条件、数値余裕を変更しない。新しい数値実験、依存ライブラリ、回復器探索、有限ショット、SPAM補正、GST、物理時計や装置全体の履歴実装を追加しない。
- C2では既存のS,F1,F2,E、Q=SF1F2を維持し、Eや参照Rへの操作、未知入力の古典記述、成功分枝の選別を与えない。R3aで記述済みの局所X測定・古典通信・SのZ補正を解析上の別資源として明示する。
- 原論文はR3aのC1（[Hofmann](https://arxiv.org/abs/quant-ph/0409083)）、C2（[Nielsen et al., GST](https://quantum-journal.org/papers/q-2021-10-05-557/)）、C3（[Horodecki–Shor–Ruskai](https://arxiv.org/abs/quant-ph/0302031)）に戻り、使う命題と仮定を確認する。既存の監査で不足がなければ文献集合を増やさない。

R3bの二基底境界は既知の方法の再現である。R3cの差分は、既存の対照と解析を『どの追加情報で何が解消するか』へ対応付け、t-searchの解釈を限定すること。新定理や新しい物理原理、網羅的な新規性監査を成果に数えない。

## 4. 実施順序・成果物・成功条件

一回のR3cとして次の順で完了させる。さらに段階名を増やして先送りしない。

1. **根拠監査:** C1–C3の式・対照・必要資源を確認し、各主張に既存文書の節、コードの関数または結果の項目を対応付ける。R3aの解析とR3bの実測を区別する。
2. **主張台帳:** `results/t_search_r3_claim_ledger.md`を新規作成する。各行に主張、根拠、前提、判定、識別のために必要な追加情報を記載する。判定は「既存成果で支持」「今回の解析照合」「追加前提が必要」「本範囲外」。歴史的台帳を書き換えない。
3. **R3総括:** `docs/t_search_r3_synthesis.md`を新規作成し、C4を含め、数式を追わなくても『回復できる・認定できる・内部資源が分かる』の違いが読める説明を添える。README/roadmapの現在欄を同期する。

**成功条件:** 次の全てを満たしたらR3cを完了とする。

- Pauli対照の二基底での不定性と、C2の合成チャネルが同じ場合の内部実装の不定性を、別の根拠で説明できる。
- L≤1/2を回復不能とせず、実行した処理のUを最適回復性能の上限としない。無記録対照の成功を記録存在の証拠にしない。
- 局所測定・通信を使う回復と、合成チャネル全体が測定・再準備型であることの違いを明示できる。
- 信頼条件ごとに、データで検証したこととモデルへ与えたことが追える。
- R2の全体履歴の結果とR3の認定結果を接続し、有限モデルの記録形成が未来の実在・非実在や存在論的生成を単独では決めないことを説明できる。
- 新規実験を必要とせず、全主張に証拠または未解決の表示があり、読者向け総括と台帳が一致する。

**中止・縮小条件:** 解析の成立に未知入力の記述、追加アクセス、ポストセレクション、モデルの拡大が必要なら当該主張を未確立へ下げる。式の不整合を発見した場合は誤りと影響を記録して修正対象を特定し、実験範囲を広げて帳尻を合わせない。既存文書の言い換えだけで四課題の区別が増えない場合は、重複を記した短い総括で終了する。

本書の定義作業ではMarkdownの差分・相対リンク・過去本文の保持を確認する。R3c実施時も文書と解析の根拠を検証し、テスト件数を理解の前進の尺度にしない。コードを変更しない限り新規テストは必須にしない。

## 5. blockness／becomingへの到達目標と終了判断

R3cが目指す説明は、**全体として記述できることと、内部から操作・検証できることは別の条件であり、その違いを明示したまま記録の形成を理解できる**、というものである。全体を記述する数学者を、全情報を操作できる物理的な『神の視点』としてモデルへ加える必要はない。一方、全知の主体を置かないことから、無条件に認定できるという結論も出ない。

ここで扱う内部変化・記録の成立は操作的な意味である。単一結果の現実化、時間の流れの経験、未来の実在を説明したとはしない。存在論へ進むには、対応する橋渡し仮定と、異なる予測または明確な説明上の課題を別途定める。

R3c完了時にはR3系列を理解・再現研究として閉じる。R3dを自動設定しない。後続候補は理解上の利益と具体的な識別条件を書けるものを最大一件だけ残し、なければ後続なしとする。本書の作成によってその後続研究を採用したとはしない。

元の `pilot_gate = blocked`、厳密な周期単一コピー候補の不採用、Stage 17凍結を維持する。R3cの終了は元の装置クラス閉性や存在論的識別の障害が解消されたという意味ではない。
