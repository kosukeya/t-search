# R4 — 関係的な事実と観測者間の整合性

2026-09-08、版 `r4-v1`。ユーザーが採用した方針を実施する新しい研究系列。基点はPR #21マージ後の `17e23c2025131983f3cfd8d9acb21ccb370ce1ed`。**R4aの[比較監査](t_search_r4a_comparative_audit.md)を完了し、R4bを次の最小再現として定義した。R4b以降は未実施。**

## 1. 目的と研究質問

全体の量子的な記述と、内部の記録の成立・利用・比較を、前提の違いを明示して理解する。存在論的生成の判定は当面の成功条件から外す。新しい量子論の解釈を名乗ることや、新規予測を出すことを必須にしない。

**中心質問:** 同じ有限回路について、記録の一致、別の観測者の事実との対応、複数時点の推論、全体履歴の表現は、どこまで共通の量子計算で扱え、どこから追加の解釈上の前提が必要になるか。

| 課題 | 到達点 |
| --- | --- |
| R4a：関係的な事実・観測者間の対応・全体履歴の比較監査 | RQM原論文、stable facts、cross-perspective links（CPL）、整合履歴を区別。対応表とR4b仕様を固定する |
| R4b：記録の比較と干渉の最小再現 | 3操作×2環境条件×4入力のBorn確率、記録の校正、履歴の干渉項を照合する |
| R4c：既存no-goとの前提の対応 | Bong et al.のLocal Friendliness一件に限定して、採用・保留・未実装の前提を対応付ける。R4bを定理全体の検証としない |
| R4d：解釈上の総括 | 状態、事実、記録、確率、全体履歴をどう位置付けるかを説明する。既存解釈との差分がなければ再構成・比較として閉じる |

ここでのblocknessは全体の量子的な過程を一つの数学的対象として表すこと。全時点・全測定の結果が同時に決まった古典的な表を意味しない。becomingは記録が形成され、利用できる情報や予測が変わる操作的側面に限定する。単一結果の成立、経験される現在、未来の実在は未解決のまま残す。

## 2. 既存研究との差分

[R2](t_search_r2_synthesis.md)は記録形成とアクセスによる回復限界、[R3](t_search_r3_synthesis.md)は性能認定と内部実装・信頼条件の違いを整理した。R4で増やすのは、**誰の、どの事象・測定文脈の命題かを保持し、他の命題へ移す根拠を明示すること**である。既知のCNOT相関やデコヒーレンスを新発見として数えない。

RQMと整合履歴の用語を一括してt-searchへ貼り付けない。CPLは監査対象の追加公準として表示し、計算の暗黙の前提にしない。全体履歴を絶対的な波動関数の実在と同一視することも採用しない。Born則、有限次元の量子形式、準備・基底・操作順序は与える。

## 3. 許容する作業と操作

R4aでは原論文・既存コードの読取り、式の解析照合、対応表・後続仕様・文書の作成を行う。新しい数値結果を生成しない。

R4bの固定仕様は[監査 §5](t_search_r4a_comparative_audit.md#5-r4bの固定仕様)を正本とする。S,F1,F2,Eの4量子ビット、既知の初期補助状態、指定CNOT、終端の射影測定・部分トレースを用いる。F1を最初の記録、F2をその後の比較用記録とする。Eへの書込みは準備過程だけに許し、その後の回復・読み出しにはEアクセスを与えない。測定確率は全結果を保持し、途中の実測と、推論のための履歴射影を分ける。

未知入力の古典記述、ポストセレクション、物理時計の実装、観測者の意識モデル、巨視的装置の制御可能性、熱力学的不可逆性、解釈を識別する実験は範囲に含めない。有限モデルを人間の観測へそのまま一般化しない。

## 4. 成功条件と中止条件

R4aは次の全てを満たせば完了する。

1. 相関としての一致とCPLによる事実の対応付けを区別し、一次資料の箇所を示す。
2. R2の制約履歴と整合履歴の条件を混同せず、同じ回路に適用する方法を示す。
3. R2/R3の成果、今回の解析、解釈上の前提、未実施の検証が追跡できる。
4. R4bの操作・出力・解析予測・判定条件を固定し、比較によって増える理解を説明できる。

R4bは、固定24条件で確率と解析値が一致し、準備の校正と単なる記録間一致を区別し、指定履歴族の干渉項によって確率を加算できる場合とできない場合を示せたら完了する。数値許容差は `1e-10` とし、統計的信頼水準とはしない。文書上の対応規則を実装したことを、RQMやCPLの物理的な証明とは数えない。

**中止・縮小条件:** 比較に追加の未記載メモリやEアクセスが必要なら、その主張を保留して仕様の改訂を記録する。異なる測定文脈の確率を無断で混ぜる必要が生じたら、その推論を採用しない。既存の再現以上の理解が増えなければ、重複と限界を記した比較報告で閉じる。解釈の新規性がないことだけを失敗とはしない。数値不一致を条件追加で隠さず、原因を特定するまで次段階へ広げない。

## 5. 過去の凍結との関係

R3の「後続未選定」は当時の完了記録であり、その後のユーザー指示によってR4を新規採用した。Stage 17の旧制約代数探索は今回の問いに必要ないため凍結を維持する。元の `pilot_gate = blocked` と厳密な周期単一コピー候補の不採用も維持する。旧障害が解消したという判断ではない。

R0〜R3の固定プロトコル、コード、結果、主張台帳を保存し、新しい判断はR4文書へ追記する。今回の作業範囲はR4aまで。R4b〜R4dは上の順序で進める計画であり、完了済み成果として扱わない。
