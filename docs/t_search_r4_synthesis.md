# R4総括 — 全体履歴、内部の記録、観測者間の事実

2026-09-09。**R4d completed。R4a〜R4dを、既存理論の再現・比較と理解の研究として総括する。** 基点は `f0edc6c9a867d9572a7d44582115afe5dfcb9e5c`、保存先は[PR #22](https://github.com/kosukeya/t-search/pull/22)。本書と[R4主張台帳](../results/t_search_r4_claim_ledger.md)は文書による総括であり、新規数値実験ではない。

**R4で得た説明は、全体の量子的な過程を表現できることと、その内部で記録が生まれ、共有され、失われることを両立させられる、というものである。** ただし、記録の相関を計算することと、観測者にとって一つの結果が成立することは同じではない。誰の事実を誰の事実へ結び付けるかには、操作の条件に加えて解釈上の選択が残る。

このため、現段階のt-searchを独立した新しい量子解釈として提出する判断はしない。既存解釈の論点を一つの有限モデルへ対応付け、何が数式から分かり、何を別に引き受ける必要があるかを見える形にしたことを成果とする。

## 1. R4で何が増えたか

[R2総括](t_search_r2_synthesis.md)では全体履歴・記録形成・アクセスによる回復の違い、[R3総括](t_search_r3_synthesis.md)では回復性能・認定・内部実装の違いを整理した。R4はそこへ、**命題の主体・時点・操作文脈を保ったまま比較する条件**を加えた。

| 段階 | 成果 | 根拠の種類 |
| --- | --- | --- |
| [R4a](t_search_r4a_comparative_audit.md) | 関係的な事実、stable facts、CPL、整合履歴を比較し、R4bの仕様を固定 | 原論文と定義・解析の監査 |
| [R4b](t_search_r4b_record_comparison.md) | 24条件で記録の校正、照合、干渉、16履歴族、5事象の全体履歴を再現 | [実装](../experiments/r4b_record_comparison.py)・[JSON](../results/r4b_record_comparison.json)・[テスト](../tests/test_r4b_record_comparison.py) |
| [R4c](t_search_r4c_observer_inference_audit.md) | Local Friendlinessの前提とモデルの不足を対応付け、3終端表の統計的拡張を解析 | 一件のno-go監査と紙上の対照。新しい数値結果ではない |
| R4d（本書） | 状態・記録・事実・確率・全体履歴を位置付け、既存解釈との重複と未解決事項を総括 | 上記根拠の統合と主張台帳 |

### 一つの例から読めること

R4bでは、SからF1へ記録を書き、必要ならF2や環境Eへ写した。その後、記録を読む、S–F1を戻す、F2へ写してからS–F1を戻す、という三つの操作を比べた。

| 操作 | 等重みの既知Z入力に対する終端記録 | ＋入力のX_S=＋確率（E_off / E_on） |
| --- | --- | ---: |
| 読む | F1/F2とも正答率1、一致率1 | 1/2 / 1/2 |
| 戻す | F1/F2とも正答率1/2、一致率1 | 1 / 1/2 |
| 写してから戻す | F1の正答率1/2、F2は1、一致率1/2 | 1/2 / 1/2 |

表はR4bの解析値と丸め誤差内で一致した保存結果の要約である。校正の列と干渉の列は入力が異なり、同じ試行で全てを観測した表ではない。

ここから、二つの装置の答えが一致しても、元の情報を伝えているとは限らないことが分かる。また、戻す操作でF1の内容が変わった後にF2と値が違っても、過去の記録について矛盾が生じたとは限らない。どの操作が間に入ったかを含めれば説明できる。

これらの変化は、分析者が同じ状態を違う言葉で呼んだだけではない。回路が結合状態と読み出せる記録を変え、その差を指定した測定で検査できる。ただし、ここでの記録装置は量子ビットであり、経験や意識を持つ観測者を実装したわけではない。

## 2. t-searchで用いる説明の位置付け

以下は今回の比較に用いる説明上の整理であり、新しい物理公準ではない。

| 概念 | 本研究で与える意味 | 別に必要な判断 |
| --- | --- | --- |
| 系・世界のモデル | S,F1,F2,Eという分解、初期化、操作列、アクセス範囲を指定した有限量子モデル | その分解が現実の観測者や世界全体をどこまで表すか |
| 状態 | 準備・操作・条件に応じた予測に使う密度行列 | それが観測者独立の実在なのか、関係的な記述なのか |
| 記録 | 校正された物理変数と、それを保存・転記・読出しする過程 | 相関した記録に、一つの実現した事実をどう対応させるか |
| 事実 | 指定した主体・事象に関する結果の主張。計算に現れる候補値と実現値を区別する | 単一性、相対性、観測者間の同定をどう定式化するか |
| 確率 | 与えた量子形式とBorn則による、指定した操作の全結果確率 | Born則の導出、有限標本の保証、単一結果の意味 |
| 全体履歴 | 同じ準備・操作列の各事象を含む、一つの量子的な表現 | 時間全体の実在や、全ての実現事象の存在論 |

例えばF1の結果で条件付けた状態を書けても、条件付けの式それ自体が物理的な収縮を起こすわけではない。実際の測定を追加した処理、読める記録を条件として使う予測、実測されていない履歴候補を推論のために分ける計算を区別する。R4bの中間Z測定対照は、この違いを数値で示した。

全体の状態を用いた計算は、指定された実験を記述するための数学的作業として扱う。その状態を全ての観測者が共有する絶対的実在だと宣言してから、同時にRQMそのものだと呼ぶことはしない。ここでは各解釈が同じモデルをどう位置付けるかを比較している。

## 3. 既存解釈との対応

比較対象はR4a/R4cで監査した定式化に限定する。以下の右二列は、文献とt-searchの対応からの本研究の判断である。

| 既存研究 | 取り込める理解 | 同一視できない部分・残る選択 |
| --- | --- | --- |
| RovelliのRQM（1996、v2） | 状態や物理量を、系と他の系との関係として考える視点 | 相関計算だけでは他者にとっての実現した事実の対応は決まらない。絶対的な全体状態を暗黙に追加しない。[原論文](https://arxiv.org/abs/quant-ph/9609002) |
| Di Biagio–Rovelliのstable facts（2021） | ある系に対して干渉を無視した確率的推論が使える条件への注目 | 正答率や記録寿命と同じ指標ではない。今回の一履歴族での整合性を、任意の後続測定に対する安定性へ拡張しない。[§1.1–1.2](https://arxiv.org/pdf/2006.15543) |
| Adlam–RovelliのCPLを加えた定式化（v2） | 記録が保たれる条件での観測者間の結果対応。相対状態と全体履歴を結ぶ説明の先例 | CPLは追加公準。著者の絶対的事象や全履歴に一括して法則を課す存在論も、そのまま採用済みとはしない。[Definition 4.1・§5–5.3](https://arxiv.org/pdf/2203.13342) |
| Griffithsの整合履歴（1996） | 履歴について確率的に推論する際、射影族と整合条件を明示すること | frameworkは物理的観測者の添字と同義ではない。伝播を満たす全体履歴Jと、射影履歴族のDの条件は異なる。[§II–V](https://arxiv.org/pdf/quant-ph/9606004) |

特にCPL論文との重複は大きい。全体の履歴と関係的な状態を組み合わせるという発想自体を、t-searchの新しい解釈の根拠にはできない。一方、重複があることは、今回の有限モデルによる理解・比較が無用だという意味でもない。読者が具体的な操作と確率へ戻って、対応の成否を追えるようにした点に価値がある。

CPL版をRQMの全ての版と同一視したり、整合履歴の規則をCPLの代わりとして使ったりはしない。両者はそれぞれ、主体間の対応と履歴内の確率的推論という別の問いに答える。今回の比較は、これらを一つの完成した解釈へ統合した証明ではない。

## 4. blockness／becomingをどう捉え直せるか

### 全体の表現の中に、内部の違いが含まれる

R4bは文脈ごとに、初期化と4操作を含む5事象の写像Jを構成した。Ω=JρJ†の各事象部分から、その事象の状態を復元できる。全体を一つの対象で表せることは、各事象の状態が同じであることを要求しない。F1に記録ができる事象と、それが消去される事象の違いも、同じ表現に含まれる。

この意味でのblocknessとbecomingは、競合する二つの力学ではない。前者は過程全体の表現可能性、後者はその内部で生じる記録と利用可能性の変化を指している。ただしこの語の整理は、存在論的な永遠主義と生成を同時に証明するものではない。

### 内部の情報制限は、全体表現の不可能性を意味しない

ある操作主体がEを利用できなくても、分析のためにG=SF1F2Eを記述することはできる。逆に、全体の式を書けたという理由でその主体へEアクセスが与えられるわけでもない。数学的に全体を記述することと、全知の物理的な主体が存在することを分けられる。

F2やEに記録が残ると、Sだけの干渉は戻らない場合がある。それは主体の気分や無知だけの話ではなく、許容された操作と記録の所在の違いである。しかし、制限された主体に未来が分からないことから、未来が存在しないとは導けない。

### 共有する事実の成立には、もう一段の説明が要る

適切な転記と校正があれば、後の記録を元の情報について使える。その操作的な対応は具体的に説明できる。そこから「他の観測者が経験したのと同じ事実を共有した」と言うには、どの結果をどの主体に対して実現したとみなすかを定める必要がある。ここを保留しても記録形成の研究は進められるが、測定問題を全て解決したとは言えない。

| blockness／becomingに関する問い | R4の到達点 |
| --- | --- |
| 全体表現と内部の記録変化は両立するか | 指定した有限モデルで支持 |
| その全体は、実現した全事実を並べた古典的な表か | Jの構成からは導かれない |
| 未来の事象は現在の事象と同じ仕方で実在するか | 判定していない |
| 新しい事象が世界へ存在論的に追加されるか | 当面の研究目的から外して保留 |
| 一つの結果や経験される現在がなぜ成立するか | 本モデルには説明の追加が必要 |

## 5. 量子履歴とno-goから受け取る制約

R4bでは、＋/undo/E_offの指定履歴族に実数の干渉項が残り、中間分枝の確率を足すだけでは元の終端予測を再現できなかった。＋iでは純虚数の交差項が残る一方、今回の終端確率は中間測定対照と一致した。従って、一組の確率の一致、弱い整合条件、複素非対角成分の消失を区別する必要がある。

しかしこの結果から、過去・現在の値を含む共同分布が全く作れないとも言えない。R4cは＋/E_offの三終端表に合う非負な統計的拡張P̃を示した。その拡張は中間射影測定の条件付き予測を再現せず、二実験室のLFモデルでもない。この二つの結果を合わせると、**どのデータ、どの条件付き予測、どの設定間の条件を同時に再現するのか**を特定する必要があると分かる。

対象としたLF定理は、観測された事象の絶対性（AOE）、NSD、条件付きLocalityと、関連する量子相関を実現する観測者を含む制御の組合せを制約する。未実行の全測定への値の付与とは異なる。[Bong et al., Theorem 1・仮定1–3](https://arxiv.org/pdf/1907.05607)

R4bには二実験室の設定やLFの条件付き分布がない。したがってAOE、Locality、CPLのどれかを実験で退けたとはしない。また、全体履歴があるというだけでLFの制約を回避したとも言えない。絶対的な単一事象を採用する解釈へ進める場合は、残りの前提との整合性を別に検討する必要がある。R4cの対応表を、その検討を省略しないための記録として残す。

## 6. 成果の位置付けと終了判断

| 成果の種類 | R4の判断 |
| --- | --- |
| 新しい物理法則・実験予測 | 提案していない。標準の有限量子形式とBorn則を使用 |
| 独立した完成形の量子解釈 | 未確立。事実の実現・主体間対応・存在論上の前提が残る |
| 既知の現象・方法の再現 | 完了。記録、干渉、履歴の整合条件を固定24条件で照合 |
| t-search内での理解の前進 | あり。記録の正確さ・一致、主体と時点、履歴の推論条件、全体表現を一つのモデルに対応付けた |
| 文献全体に対する新規性 | 未確立。全体履歴と関係的記述の組合せには既存の先例がある |

**R4系列はここで完了とする。** 終了するのは今回の有限な再現・比較課題であり、blockness／becomingという問い全体ではない。未解決事項があることだけを理由に次のStageを自動追加しない。

後続を新たに選ぶ場合は、追加する仮定、既存結果では答えられない問い、比較によって得られる説明、終了条件を先に固定する。今回の成果から新しい解釈を名乗ることは必須ではない。R5やR4eは本書では選定していない。

元の `pilot_gate = blocked`、厳密な周期単一コピー候補の不採用、旧Stage 17凍結は維持する。R4の完了は、旧研究の装置クラス閉性や時計実装の障害が解消したという判断ではない。

## 7. 根拠・検証と完了条件

R4b実装head `1a8f79b04bdb7a9b7f356858048e9089a9af0a91` のPR/push CIは成功済みで、[PRログ](https://github.com/kosukeya/t-search/actions/runs/34221359936)で1405テスト・18サブテスト成功を確認している。これはR4d headの検証結果ではない。R4c・R4dの各headの最新CI状態は[PR #22](https://github.com/kosukeya/t-search/pull/22)で区別して記録する。
