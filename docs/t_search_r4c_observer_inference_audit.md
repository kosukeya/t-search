# R4c — 観測者間推論と既存no-goの監査

2026-09-09、版 `r4c-v1`。**R4c completed。** [R4プロトコル](t_search_r4_protocol.md)で選定したBong et al.のLocal Friendliness（LF）一件について、前提と[R4b](t_search_r4b_record_comparison.md)の対応を監査した。基点は `1a8f79b04bdb7a9b7f356858048e9089a9af0a91`、作業先は[PR #22](https://github.com/kosukeya/t-search/pull/22)。新しい数値実験・LF不等式の検証は行っていない。

**結論：R4bは、観測者間で推論するときに操作・事象・記録の区別が必要なことを示すが、LFの前提のどれが自然界で破れるかを決めていない。** 全体履歴と内部の記録を両立させる説明は続けられる。ただし、それを観測者から独立した単一事実の存在論へ進めるなら、局所性や観測者を含む制御について別の判断が必要になる。

## 1. 今回の質問・方法・完了条件

**質問:** R4bの「記録が一致する／消える」「指定履歴族の干渉項が消える／残る」という結果は、他者の結果への推論と、LF定理のどの前提に対応するか。

作業は原論文の指定箇所、保存データ、既存コードの読取りと解析に限定した。成功条件は、三つのLF前提と制御条件を分けること、実際の読出しと他者の事実の同定を分けること、R4bの干渉から過剰なno-goを導かないこと、R4dへ持ち越す解釈上の選択を明示すること。対応のために二実験室・新しい測定設定が必要なら、その部分は未実装と判定し、今回の実験範囲を増やさない。

原論文は次の二件に限定して再確認した。文献群全体の新規性調査や、RQMの全ての定式化に対する判定ではない。

## 2. LFの前提を、計算上の条件として固定する

論文の記号は、二つの実験室の友人の結果c,d、外側の測定設定x,yと結果a,b。x=1、y=1は対応する友人の記録を読む設定である。LFは以下の三前提の組合せ。関連する量子的相関を実現する観測者・環境への制御と両立しない、というのが対象定理である。[Bong et al., Theorem 1・仮定1–3](https://arxiv.org/pdf/1907.05607)

| 前提 | このシナリオで使われる条件 |
| --- | --- |
| AOE：Absoluteness of Observed Events | 実際の観測事象が単一で絶対的であり、非負・正規化されたP(a,b,c,d\|x,y)が終端統計を再現する。読出し設定ではa=c、b=d |
| NSD：No-Superdeterminism | P(c,d\|x,y)=P(c,d) |
| L：Locality | P(a\|c,d,x,y)=P(a\|c,d,x)、P(b\|c,d,x,y)=P(b\|c,d,y) |

条件付き確率は条件事象の重みが正の範囲で用いる。AOEの終端統計への対応は `p_obs(a,b|x,y)=Σ_{c,d}P(a,b,c,d|x,y)`。未実行の全ての測定結果に同時に値を割り当てることは要求していない。Lはc,dで条件付けした条件であり、終端統計だけのno-signallingや、結果独立性を加えた因数分解と同義ではない。[同論文、仮定の定式化と含意の節](https://arxiv.org/pdf/1907.05607)

この前提の記述から、t-searchの解釈について直ちに「AOEを捨てる」「非局所性を採用する」と決めない。まず、対象となる二実験室の変数と相関がt-searchに存在するかを調べる。

## 3. R4bとの対応表

ここで「採用」はR4bのモデルに与えた条件、「支持」はその条件の下で確認した数値・解析、「保留」は存在論上の判断をしていないこと、「未実装」は判定に必要な構造がないことを意味する。

| 対象 | R4bでの具体的な根拠 | 判定と不足 |
| --- | --- | --- |
| 準備・量子操作・Born則 | `model`、`case`、各8結果の `terminal_probabilities` | **採用。** 信頼された有限行列の計算であり、法則や装置の独立な認定ではない |
| 友人の記録を後で読む操作 | F1→F2、`read`の校正と終端Z_F1/Z_F2相関 | **支持。** 一実験室の物理的な転記。二つの友人と二つの外側測定者への完全な対応ではない |
| 記録を含むコヒーレント制御 | `undo,E_off`でS–F1を戻す | **限定的に支持。** 指定されたゲートだけ。任意の観測者・環境への普遍的な制御は未実装 |
| AOE | F1の過去の値を無条件の実現値として保存していない | **保留。** プログラムに変数がないことは、その事実が実在しないという証明ではない |
| NSD | 同じ初期状態に別の操作列を適用し、入力ごとに計算 | **未実装。** 二実験室のc,d,x,yと設定選択の物理過程がない。ループで設定を列挙したことをNSDの検証としない |
| L | Eへ読出しアクセスを与えないこと、指定ゲートの対象 | **未実装。** 時空分離・二つの設定・c,d付き条件分布がない。アクセス制限は相対論的な局所性とは異なる |
| LFの共同分布・不等式 | 一つの文脈に対する8結果と16履歴のD | **未実装。** DをP(a,b,c,d\|x,y)に置き換えず、不等式違反値を報告しない |
| CPLによる他者の事実との対応 | 記録保持・消去・転記の区別を計算できる | **追加前提として保留。** CPLを認定する出力や隠れた元の結果はない |

F1とF2は別のレジスタだが、これだけでLFの二実験室にはならない。F2はF1から時間順に情報を受け取る。同じ系に順番に行う操作を、空間的に離れた独立の設定選択と同一視しない。

E_onで干渉が戻らない結果も、普遍的な観測者制御が根本的に不可能だという証明ではない。アクセス集合を固定したことによる結果である。逆にE_offで成功しても、人間や任意の環境へその制御を拡張できるとは言えない。

## 4. 観測者間推論で、どの移し替えを許せるか

R4aの命題の型を、今回の結果へ具体化する。uは事象2のF1の候補値、f1,f2は事象4の読出し、sは終端X_S結果、kは操作文脈。uをLF論文のcと直接同定してはいない。

| 推論 | 判定 | 必要な区別 |
| --- | --- | --- |
| `read`の終端でf1=f2である | 指定回路・準備の下で支持 | 同じ文脈の可換な読出し統計 |
| だから双方とも元の情報を正しく伝えている | 一致だけでは不足。校正を併用 | `undo`では一致率1でも、等重みZ校正の各正答率は1/2 |
| 後のf2が、F1にとって成立した元の結果そのものである | 解釈上の橋渡しが必要 | 計算された相関と、他者の相対的な事実の同定 |
| `undo`後のf1=0を過去のuへ代入する | 採用しない | 事象2と4の間に消去操作がある |
| `copy_undo`のf1とf2の不一致は観測者間の矛盾である | この結果からは導けない | F2への転記は残るが、F1はその後に戻される |
| Dの対角を足した値が元の回路の終端確率である | 干渉項を確認してから判断 | 中間のZ測定を実際に挿入した回路と、元の回路は異なる |
| Dが非整合なら、いかなる過去・現在の共同分布も存在しない | 導けない。次節の対照 | 特定の量子履歴の重みと、任意の統計的拡張の存在は別問題 |

同じ文脈のデータの周辺化・条件付けと、文脈や記述主体を変えた命題の同定は別の操作である。前者はその確率空間で行える。後者には、転記の過程や採用する解釈の規則が必要になる。

## 5. 今回の解析対照：R4bの干渉は共同分布一般の不存在を示さない

保存JSONの **＋入力・E_off・3文脈だけ**を用いる。終端結果はz=(s,f1,f2)、s∈{＋1,−1}。u∈{0,1}を形式的な補助変数として導入し、次の分布を紙上で構成する。これは新しい実験、実際に保存した過去の記録、LFモデルではない。

$$
\begin{aligned}
\widetilde P(u,s,f_1,f_2\mid\mathrm{read})
 &=\tfrac14\delta_{f_1,u}\delta_{f_2,u},\\
\widetilde P(u,s,f_1,f_2\mid\mathrm{undo})
 &=\tfrac12\delta_{s,+1}\delta_{f_1,0}\delta_{f_2,0},\\
\widetilde P(u,s,f_1,f_2\mid\mathrm{copy\_undo})
 &=\tfrac14\delta_{f_1,0}\delta_{f_2,u}.
\end{aligned}
$$

これはR4bの保存表から今回作った**解析上の統計的拡張**である。各文脈で非負、全変数について和を取ると1。全ての文脈で `P̃(u|k)=1/2`。uを足すと、readではsごとに(0,0)/(1,1)が各1/4、undoでは(＋1,0,0)が1、copy_undoではsごとに(0,0)/(0,1)が各1/4となり、保存された8確率と丸め誤差内で一致する。

この拡張のundoでは `P̃(s=＋1|u,undo)=1` である。他方、実際に事象2でZ測定を行ったR4bの対照は、各中間結果に対してX＋確率1/2を与える。従ってP̃は**中間の射影測定で得られる分枝確率を再現するモデルではない**。まさにその違いにより、Dの非対角成分が残ることと、終端統計に合う何らかの非負な拡張の存在が両立する。

ここで示したのは、この三つの終端表についての存在証明だけである。全24条件、任意の中間介入、二実験室、LFのL条件、任意の量子状態・測定を再現するモデルへ拡張していない。uを実在する事実と宣言せず、CPLも証明していない。`P̃(u|k)`が一定であることを、時空的なNSDの実験的検証とも呼ばない。

この対照によって、R4bの「指定した履歴族でBorn分枝を古典的に足せない」を、「AOEが否定された」へ移す推論の不足を特定できた。LFの本格的な制約は、さらに二実験室の対応と設定間の条件を同時に課す問題であり、この小さな表では評価していない。

## 6. CPLと全体履歴の解釈から学べること

CPLは、元の記録情報が保たれ、対応する変数を適切に読み出す場合の結果対応を追加する公準である。対象v2は、相対的な量子状態と絶対的な量子事象を組み合わせ、§5.2–5.3では全履歴に一括して法則を課す解釈と非局所性も提案している。[Adlam–Rovelli、Definition 4.1・§5–5.3](https://arxiv.org/pdf/2203.13342)

この既存提案との重複から判断すると、「状態は関係的だが全体の履歴も考える」という発想だけではt-searchの新規性は成立しない。R4dでは、既存提案を説明可能な有限モデルに対応付ける成果をまず目指すのが妥当である。これは本監査からの研究上の判断であり、その提案全体を採用したという意味ではない。

特に次の点を分ける。

- **関係的な状態と、関係的な事実は同じ宣言ではない。** 状態だけを相対化しても、AOEを拒否したことにはならない。
- **記録の消去は、過去の事象が絶対的だった可能性を論理的に消さない。** CPLの保存条件が使えなくなったことと、AOEの反証を混同しない。
- **全体履歴を数学的に表すだけでは、事象の存在論は決まらない。** R4bのJは量子的な状態の写像であり、実現した単一事象の分布ではない。
- **著者が非局所的と呼ぶことだけでは、LFのL条件の違反箇所を同定できない。** 具体的なP(a,b,c,d|x,y)に戻って、どの条件が成立しないかを調べる必要がある。終端no-signallingを保つことだけでもLは認定できない。

したがって本監査は、CPLだけからLFとの整合性／不整合性を一括判定しない。もし将来、絶対的な実現事象・NSD・LF違反を与える量子制御を同時に採用するなら、LFのLを同時には維持できない、という条件付きの制約は引き受ける必要がある。このt-searchへの含意は対象定理からの推論であり、R4bがL違反を観測したという主張ではない。

## 7. R4dへ持ち越す説明の方針

**当面は、操作上の対応を確定した説明と、存在論上の選択を並記する。** 新しい解釈の公準を先に追加しない。

| R4dで説明する項目 | 今回から受け取ること |
| --- | --- |
| 状態と全体履歴 | 初期条件・操作・アクセスを与えるモデル。数学的な全体記述を全知の物理的観測者と同一視しない |
| 記録と事実 | 物理的な転記・校正は計算済み。観測者にとっての単一事実は追加の解釈上の項目 |
| 確率と観測者間推論 | Born確率、選んだ履歴族の整合条件、CPL等による主体間の対応を分離 |
| blockness／becoming | 全体表現と内部記録の変化の両立を説明する。存在論的生成・経験される現在の判定は保留 |
| 既存研究との差分 | RQM/CPL・整合履歴との対応と、R4bの有限再現が理解をどう助けるかを示す。独立の新解釈であることを必須にしない |

もしR4dで事実を全面的に相対化する案を選ぶなら、別の観測者の事実への対応規則が必要になる。絶対的な単一事象を残す案を選ぶなら、LFの残りの前提について判断が必要になる。観測者制御を制限する案を選ぶなら、単なる技術的困難や現在のQアクセス制限を、原理的な不可能性へ置き換えない。今回はこれらの存在論上の選択を決定していない。
