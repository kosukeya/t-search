# R5 — 記録を事実として使える範囲と量子的な延長可能性

2026-09-11、版 `r5-v1`。ユーザーがR5aを指示したことを受けた研究プロトコル。基点はR4d head `5f71678a922f1b8ade15523437e1b18888f2b5c0`。[PR #22](https://github.com/kosukeya/t-search/pull/22)は確認時点で未マージ、当該headのPR/push CIは双方success。R5はR4成果を引き継ぐ別ブランチで扱い、R4をマージ済みとは記さない。

**R5a completed。** [定義・文献・識別可能性の監査](t_search_r5a_definition_audit.md)により、限定したR5bの実装仕様を固定した。R5b〜R5dは計画であり未実施。R5aは文書と解析の作業で、新規数値実験ではない。

## 1. 目的と研究質問

指定した記録を古典的な分枝ラベルとして扱う近似が、許容する後続操作の全体に対して、どれだけ予測を保つかを調べる。blockness／becomingへの理解を目的とし、存在論的生成の判定は保留する。

**中心質問:** 記録形成後の同じ量子状態について、記録基底の非選択的デフェージングを施した対照との予測差は、記録読出しのみ・Qへの共同アクセス・環境を含むGへの共同アクセスでどう異なるか。

ここでの「安定」は、指定した状態対・基底・操作範囲に対する予測の安定性に限定する。記録寿命、校正精度、CPL、単一結果の実現、全観測者の絶対的事実、全履歴の共同分布の存在を一括して認定しない。

## 2. 既存成果との差分と方法

R4bの個別終端測定・固定履歴族と、R4cの三終端表の統計的拡張を引き継ぐ。R5では比較する古典化写像を先に一つ固定し、**許容操作の集合に対する最悪予測差と、その上限・達成可能性**を扱う。一般の古典モデルの不存在を検証する計画ではない。

既存のstable facts、非客観性witness、量子状態識別との重複を監査で明示する。新規な量子原理・距離・解釈を提案したとは数えない。追加価値は、同じ記録の校正、部分的環境記録、位相に鈍感な検査、アクセス範囲を一つの最小例へ対応付けることにある。

## 3. 固定する操作と範囲

- 系はR4bと同じ順序の4量子ビットS,F1,F2,E。Q=SF1F2、G=QE。初期補助状態は000。
- S→F1のCNOT後、F1制御でEへ一パラメータのユニタリを作用させる。比較時点はR4bの事象2、環境工程の直後・F2への転記前。正本の式は監査§3。
- 対照は同じ時点のF1のZ基底デフェージング。全分枝を保持するCPTP写像で、選択結果による正規化や物理的収縮を仮定しない。
- 読出しのみのクラスはF1/F2のZ読出しと古典後処理。Q/Gクラスは各領域内の全POVMおよび同じ決定論的局所処理。Qクラスでは比較時点以後、Eとの再相互作用も環境リセットも禁止する。GクラスはEアクセスを明示的に与えた別の資源対照。
- 独立な補助系は許すが、入力と相関した追加参照、複数コピーの共同測定、選別した成功結果だけの比較は含めない。理想的な操作集合の解析であり、実機のゲート集合・内部時計・制約保存装置の実装保証ではない。
- R5bの主比較は角度5点×入力5条件の25状態対に固定する。R4bの端点24条件との照合と、無記録の負の対照を別枠で行う。詳細は監査§6。連続パラメータ全体の結論は解析を根拠とし、点の走査を証明としない。

## 4. 指標と段階

指標は、二つの説明を同じ許容操作・測定へ通した全結果分布の全変動距離の上限。Q/Gの全測定クラスでは各縮約状態対のトレース距離に等しい。単一測定の差と最大値を区別する。

物理的な近似許容値をεとし、最大予測差がε以下なら、その指定クラスに対してのみ「ε以内の予測近似」と呼ぶ。浮動小数点許容差 `1e-10` はεでも統計的信頼水準でもない。

## 5. 成功・中止・範囲変更の条件

R5aの成功条件は、状態対の正規化・写像の完備性、最大化する操作集合、先行研究との不一致点、解析的な差と零の対照を明示し、後続を再現可能な有限課題にすること。監査末尾の台帳で満たす。

R5b以降では、有限点の一致を操作一般の保証へ拡大しない。上限と達成器が一致しない場合は原因を調べ、仕様にないアクセスや位相情報を後付けしない。Eの再結合、結果選別、未記載の参照が必要になれば、元のクラスについての主張を保留し、別条件として再設計する。

既存の再現以上に説明が増えなければ、文献対応と限界を記録して縮小・終了する。新規性がないこと自体は失敗ではない。古典化の予測精度を存在論的生成や絶対的事実の証拠へ結び付けることが必要条件になった場合は、その課題をR5から外す。巨大環境、熱力学的時間の矢、意識、宇宙論、LF違反の探索は追加しない。
