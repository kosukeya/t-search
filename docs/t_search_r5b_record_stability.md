## 1. 何を比較したか

S,F1,F2,Eの4量子ビットを使う。SからF1へ記録を書き、続いてF1制御でEへ部分的な記録を作る。比較時点は環境工程直後の事象2で、F2へ転記する前である。Q=SF1F2、G=QE。

この時点の量子状態ρと、F1のZ基底の干渉項を除いたΔ(ρ)を比較した。Δは二つの結果を全て加えるCPTP写像で、結果を選別しない。後者の予測が合うことから、実際に単一の結果への収縮が起きたとは判断しない。

| 成果物 | 内容 |
| --- | --- |
| [実験](../experiments/r5b_record_stability.py) | 行列による準備・部分記録・古典化対照、測定分布、距離、既存端点との照合 |
| [保存JSON](../results/r5b_record_stability.json) | 25状態対のG/Q行列、複素重なり、全読出し結果、解析残差、24端点、校正・負の対照、来歴 |
| [テスト](../tests/test_r5b_record_stability.py) | 全基底・全入力演算子基底、位相、完備性、既存結果、保存データとの照合 |

角度は0,π/6,π/4,π/3,π/2、入力は0,1,＋,＋i,I/2。θは一回の記録相互作用の強さを指定し、経過時間ではない。ゲートはR5aの式どおり、θ=0で恒等、θ=π/2でCNOT(F1→E)に全空間で一致する。

## 2. 操作範囲ごとの最大予測差

ρSの非対角成分をc、環境の条件付き状態の重なりをγ=e^{iθ}cosθとする。R5aで導出した式は

$$
d_{C_Z}=0,\qquad d_{C_Q}=|c|\cos\theta,\qquad d_{C_G}=|c|.
$$

C_ZはF1/F2のZ読出しと古典後処理、C_Q/C_GはそれぞれQ/G上の全POVMである。数値ではQ/Gの状態対のトレース距離を特異値から求め、独立な支持上の解析式と照合した。最大予測差との等価性はR5aの状態識別の議論による。有限個の測定を走査して最大値を証明したわけではない。

| θ | ＋／＋iのZ読出しの差 | ＋／＋iのQ最大差 | ＋／＋iのG最大差 | ＋入力を戻してXを読む場合の差 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 0 | 0.5 | 0.5 | 0.5 |
| π/6 | 0 | 0.433013 | 0.5 | 0.375 |
| π/4 | 0 | 0.353553 | 0.5 | 0.25 |
| π/3 | 0 | 0.25 | 0.5 | 0.125 |
| π/2 | 0 | 0 | 0.5 | 0 |

表は解析値と一致した保存結果の丸め表示。JSONでは小さな浮動小数点成分も切り捨てず保存する。0/1/I/2入力はc=0なので、全角度・全クラスで差は0である。

環境に完全な記録を作ると、Qだけでは古典化した対照と区別できなくなる。一方、Eを含むGにアクセスする資源対照では、＋／＋iの差は1/2残る。このQの結論には、比較後もEとの再相互作用を許さない条件が必要である。Eの消去・再準備は行っていない。

## 3. 一つの検査の零と、クラス全体の零は違う

事象2からS→F1のCNOTを戻してX_Sを読む固定検査では、二つの説明のX＋確率の符号付き差はRe(cγ*)となる。＋入力ではcos²θ/2、＋i入力では−sinθ cosθ/2であり、複素位相を落とすと後者を再現できない。

特に＋i/θ=0では、両方の説明がX結果(＋,−)に(1/2,1/2)を与える。それでもQのトレース距離は1/2である。固定X検査の感度不足と、クラス全体の識別不能は異なる。

θ=π/4ではγ=1/2+i/2。＋iの量子的予測は(1/4,3/4)、古典化対照は(1/2,1/2)となった。最大差1/(2√2)と、この検査の差1/4も区別して保存した。

最適測定の具体的なゲート実装と資源対応はR5cに残す。R5bでは最大値に等しい状態距離の再現と、固定検査の差を扱った。

## 4. 記録の正確さと予測近似は別条件

本状態族のF1は全角度で、既知Z入力0/1を等重みにした校正に対し正答率1だった。F2はまだ準備状態0で、正答率は1/2。この時点の二装置を共有記録として扱っていない。

他方、無記録対照ρS⊗|000⟩⟨000|では、F1デフェージングは状態を変えないため全クラスの予測差は0。それでもF1の校正正答率は1/2である。**予測差が小さいことだけから、元の情報について正確な記録があるとは言えない。**

＋／＋i／I/2に既知のZ結果を入力ラベルとして付けていない。校正欄はnullとし、0/1の校正と混ぜない。

## 6. 解釈と次段階

今回の再現は、「古典的な記録として扱う」という近似が、指定基底と操作範囲に依存することを具体化した。記録の正確さ、固定測定の感度、操作クラス全体の識別能力を分けて説明できる。

ここでの古典化は一つの比較写像である。一般の古典モデルの不存在、単一結果の成立、CPL、絶対的事実、存在論的生成を判定していない。θを時間と読んで時間の矢を導くこともしない。R4で構成した全体履歴へΔ対照も自動的に入るとは主張しない。

R5bは固定した再現課題として完了。次はR5cの「操作範囲ごとの保証と反例」として、R5aの上限を達成する読出しを操作へ対応付け、アクセス変更でどの保証が失われるかを検証する。R5c/R5dは未実施。旧Stage 17凍結、blocked pilot、厳密な周期単一コピー候補の不採用を維持する。
