# R0〜R1b 総括 — 全体的な履歴と、内部で記録が形成されること

2026-09-05。目的: **blockness／becoming への理解を深める**。状態: R0、R1、R1b、およびユーザー指示による[周期境界の補足比較](t_search_boundary_supplement.md)を完了。新しい物理理論の発見や、存在論の決着を成果条件にしない。

**この系列で具体的に確認できたのは、内部の相互作用によって記録が形成されることと、その過程全体を一つの制約を満たす履歴として記述することが、この有限モデルでは両立するという点である。** R1b の障害を作ったのは、全体的な履歴記述そのものではなく、装置を記録作成前の状態へ周期的に戻す条件と、追加のポインタ操作を禁じた予算の組合せだった。

これは「未来も現在と同じ意味で実在する」「新しい事実は本当には生じない」という証明ではない。一方で、記録の形成を示しただけで「未来が非実在から実在へ移る」とも結論できない。**記述上の性質と、世界についての存在論的主張の間には、追加の根拠が必要である。**

## 1. 各段階で何が明確になったか

| 段階 | 得られたこと | 得られていないこと |
| --- | --- | --- |
| [R0](t_search_redesign_protocol.md) | 同じ実験の確率、実行可能な操作集合、記録の役割を別の問いにした。資源と中止条件を明示した | 新しい判定基準の物理的妥当性や新規性 |
| [R1](t_search_r1_preflight.md) | 関連文献との重複を特定。裸の読み出し、物理観測量、時間指定の装置を区別した | 物理観測量の共変性だけから装置を実装できるという保証 |
| [R1b](t_search_r1b_readout_design_audit.md) | 装置を含む有限制約族を構成。単一コピーと共通準備が周期境界で衝突することを示した | 元の予算を満たす非自明な周期読み出し実験 |
| [境界の補足](t_search_boundary_supplement.md) | 終端を閉じない場合、任意の準備から一回の記録形成が成立。その履歴は補償付き周期モデルと同じ零空間に入る | 異なる制約の全面的な物理同値性、時間の向きや存在論的生成の創発 |

これらは既存理論を具体例へ適用した設計監査・再現・概念整理である。失敗を成功へ言い換えてはいない。元の周期・単一コピー候補は不採用のままで、補足は障害の原因を切り分ける別の比較だった。

## 2. この総括で使う blockness／becoming の意味

この二語を一つの性質へ固定せず、議論する水準を分ける。以下は今回の説明用の区別であり、既存の哲学的立場を定義し直すものではない。

| 水準 | 今回扱えた意味 | 追加の根拠を要する意味 |
| --- | --- | --- |
| blockness | 複数事象の状態・相関・操作を、一つの全体的な履歴にまとめられる | 過去・現在・未来の出来事が等しく実在する |
| becoming | 条件付きの状態が事象間で変わり、操作によって記録相関が形成される | 世界に新しい事実が存在論的に加わる、未来がまだ実在しない |
| 流れ | この系列では直接測定・モデル化していない | 現在が移動することや、主体に時間の流れが体験されること |

モデルでコピー前のポインタは0に準備され、コピー後には M の指定基底の値と相関する。その変化は、単に時計のラベルを付け替えただけではなく、明示した相互作用によるものである。しかし、ユニタリな相関形成と Born 確率だけでは、一つの結果がどう現実化するかという測定の解釈問題まで解いていない。

したがって「内部では記録が形成される」という操作的な説明と、「全体を一つの履歴で表せる」という数学的な説明は、この例では競合しない。異なる事実を主張する二つの物理理論として比較したわけでもない。

## 3. 全体が定常でも、内部の記録は変わり得る

補足の履歴は `H_open|Ψ>=0` を満たす。同じ Ψ の A/e0、A/e1、A/e2 への条件付けによって、準備、コピー後、最終事象の状態が得られる。

ここでの「定常」は制約に関する数学的性質である。事象間の条件付き状態がすべて等しいという意味ではない。また、全体の履歴を数式で書けることは、内部の主体がその全情報を読めることを意味しない。モデルにはそのような全知の観測者も、意識を持つ主体も追加していない。

関係的な測定を装置・記録ごと全体の制約へ含める方法には既存研究がある。[Hausmann et al.](https://arxiv.org/html/2308.10967v4) は観測量としての測定と装置相互作用としての測定を区別し、[Baumann–Lock](https://arxiv.org/html/2603.08845v1) は介入設定ごとの制約族を扱う。今回の両立性の確認は、その研究方向に沿った有限例であり、新しい存在論的原理ではない。

## 4. 周期性は blockness の必須条件ではなかった

R1b は一周後の状態を最初へ戻すよう要求した。この条件の下では、N が0から1へ変わった成分をそのまま保持できない。逆操作があれば戻せるが、一周期の装置予算が変わる。

補足では最後の復帰条件を外した。すると記録を持つ状態で実験区間を終えられる。それでも全体的な履歴表示は成立した。したがって、**このモデルで記録と衝突したのは、全体記述の存在ではなく、特定の周期的復帰条件である。**

さらに、補足の履歴と、逆操作を含む周期対照の履歴は同じ零空間を共有する。このため同じ三事象の履歴だけを見ても、どちらの制約を採用したかを決められない。ただし制約行列・非零スペクトルは異なり、モデルを変更した後の予測まで同じだと証明したわけではない。

この区別は、全体的な構造が存在するというだけで記録形成を否定したり、記録形成があるというだけで全体記述を否定したりする議論を、この有限例の範囲で退ける。

## 5. 時間の向きについて、何を与えていたか

今回の実験には、N を最初に0へ準備すること、既存の M への記録形成、M→N のコピーの順序、終端で結果を読むこと、という条件を与えた。これらを初めから採用して、そこから時間の向きが自発的に生じたと主張することはできない。

記録が前後を区別する手掛かりになることと、その区別を生む準備条件の由来を説明することは別の課題である。本モデルでは、宇宙の初期条件、熱力学的な不可逆性、安定した古典記録の長期保存、時間経験の成立は扱っていない。

## 6. 主張の範囲と、この課題の完了

| 主張 | 判定 |
| --- | --- |
| この有限モデルでは、記録形成と全体的履歴表示が両立する | 証明・検算済み |
| R1b の単一コピー候補は、固定した周期・準備・予算を同時に満たさない | 維持 |

| 同じ履歴を持つ制約は、あらゆる物理的問いで同値である | 主張しない |
