## 一課題・選定理由

**古典的な過去の記録が次ブロックの処理を変えるとき、独立試行を仮定せず、どの平均量子処理への有限記録保証を維持できるか。**

[前回](t_search_temporal_average.md)は非適応的な独立列であった。記録が後続へ作用する最小のフィードバックを許し、過去に条件付けた予測可能平均と、固定した母集団平均・事後条件付き状態・将来処理を分ける。一般の量子メモリや実機認定まで拡大しない。

## 仮定・許容操作・変更

- nブロックと五設定を事前固定。古典的な全過去F_(t−1)から、ブロックtの量子ビットCPインストゥルメントΦ_t,b(F_(t−1))を選ぶ。五設定には同じ処理を使い、ブロック内はその処理を固定。各使用の量子入力/環境はリセットし、量子メモリを試行間に持ち越さない。古典的な記録・制御だけを持ち越す。現在の設定/結果を使った先回りの変更・選別は認めない。
- Y_t,j∈{0,1}の過去条件付き平均p_t,j=E[Y_t,j|F_(t−1)]を使う。検証対象は実現した過去に沿う予測可能平均Φ̄_b(H)=(1/n)Σ_tΦ_t,b(H_(t−1))。ランダムな対象であり、固定した未知チャネル、全過去H_nへ事後条件付けた装置、無作為に選んだ実測試行や次の試行の状態と同一視しない。
- 同じ名目入力・測定・固定実際準備、次元・配線・共通ブロック/重み・決定論的な校正予算は前回から保持。計算対照は校正予算ゼロ。独立性を条件付き期待値の仮定へ置き換える理由と、ブロック内固定を維持する理由を報告する。旧exact_probabilities認定器は呼出しも変更もしない。
- 条件付きHoeffding補題から、片側の加法余裕ε_n=sqrt(log(5/α)/(2n))を使う固定nの同時下限を導く。α=0.05。前回の独立列用KL下限をそのまま流用することは認定しない。任意停止・反復全体の保証は含めない。

## 固定する評価・成功・中止条件

1. Bernoulliの条件付き対数MGFの二階微分≤1/4から指数超マルチンゲールと固定nの尾を導き、五母数・校正補正・Hofmann下限・分枝上限へ経路ごとに接続する。一次資料の対応箇所を確認する。既知原理の適用を新定理とは呼ばない。
2. 単一スコアのp_t∈{0,1/2,1}を過去から選べる有限制御クラスを、n=8,25,100で監査。状態(t,S,C)（C=2Σp）から正確な整数の後向き動的計画法で、旧KL/新加法下限が予測可能平均を超える最悪確率を求める。得た方策の前向き分布計算と、n=8の全2^8公平ビット列の独立実行で照合する。旧法の失敗が見つからなくても陰性結果を保存する。
3. 量子対照はΦ_t,0=q_t Z(·)Z、Φ_t,1=(1−q_t)id。初期記憶0、第五設定のエラーフラグを次の記憶にし、q(0),q(1)=(0.1,0.9),(0.9,0.1),(0.5,0.5)の三規則に固定。n=4,8,12で三つの非自明カウントと最終記憶の全分布を有理数DPで計算し、経路依存平均への同時下限の失敗と条件付き誤差の偽保証を評価する。ブロック内の三試行は条件付き独立とする対照である。
4. 同じ三規則の長さ8の全256フラグ履歴ごとに、予測チャネルのKraus平均と直接平均を照合。＋、0、(I+0.2X+0.3Y+0.4Z)/2の三入力・両分枝を検算する。Bell忠実度・四正答率・分枝確率と、履歴からの明示的q列/カウント式を別に照合する。未来や事後状態への保証とはしない。
5. 各n=1000,100000,20000000、四検査全成功でフラグ回数nまたはn/100の六構成例と、n=4000000000で五設定全成功の一例を計算する。実測や大量ショットの実行・最小試行数とは報告しない。εと線形補正を80桁Decimalで照合し、保守側へ丸める。
