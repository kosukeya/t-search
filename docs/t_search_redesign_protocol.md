## 1. 再開の位置づけと研究質問

ユーザーの再開指示に基づき、同じリポジトリで新しい問いの設計を再開する。[終了判断](t_search_closure_decision.md)が凍結した Stage 16 の探索拡大とは別の R 系列とし、歴史的 Stage 17 は選定済み・未着手のまま保持する。[最終主張台帳](../results/t_search_final_claim_ledger.md)の結果・未決着・存在論的限界は変更しない。

再開理由は、許容する変換を探索上の便利さだけで決めず、**明示した装置・記録・操作資源から定める**という判定基準の導入である。この基準の物理的妥当性・新規性はまだ未検証であり、終了判断が求める新しい定理や存在論的橋渡しを獲得したとは扱わない。

> 時計変更の下で、同じ介入実験の確率と、内部から実行可能な介入の集合は、それぞれどの条件で保存されるか。記録へのアクセスはその条件にどう関与するか。

- **RQ1（記述の同値性）:** 対応する出来事で同じ物理的装置・操作を変換したとき、介入列の全結果確率は一致するか。
- **RQ2（操作可能性）:** 独立に物理的実装を定めた介入クラスは、時計変更で閉じるか。閉じなければ、失われる実行可能性をどの資源条件が説明するか。
- **RQ3（記録の役割）:** 同じ過程・課題・資源予算で、記録を利用できることは予測・制御の成功率をどう変えるか。

RQ1 の共変性、RQ2 の操作能力差、RQ3 の課題上の差を別々に判定する。異なる装置能力の比較を「時計の物理的不整合」と呼ばない。

## 2. 既存研究との差分と新規性の確認

| [Milz–Pollock–Modi, 2018](https://arxiv.org/abs/1610.02152) / [Berk et al., 2021](https://arxiv.org/abs/1907.07003) | 制限された操作による再構成、操作資源と記憶の役割 | 時計変更と独立な装置制約を同時に固定したときの閉性・必要資源を調べる |

これは差分の**候補**であり、新規性の宣言ではない。次の事前監査で上記文献の関連する定理・仮定と後続研究を確認し、各候補を「既知の帰結 / 適用条件が未充足 / 未解決の候補」に分類する。単なる共変性の再現や操作クラスの定義から直ちに従う結論は再現結果として記録する。

## 3. 最小モデルと許容する操作

第一候補は Stage 7 の既存 `A/B/C/M` モデルを再利用し、**A と C を時計、B を対象、M を記録**とする構成。新しいテンソル分解を仮定せず、物理部分空間と各時計の支持空間を継承する。二つの介入事象 `e0,e1` と最終測定 `e2` に限定する。出来事の対応は明示し、等しい時計数値や Python の実行順序で同一事象を定めない。

介入は結果ごとの完全正値・トレース非増大写像からなる **instrument（測定結果と測定後状態を与える操作）** とし、全結果の和はトレース保存とする。適応的操作は既に得た記録だけに依存できる。隠れた未来・継続選択子を参照しない。

| 操作候補 | 採用条件 |
| --- | --- |
| 恒等操作・M の読み出し | 読み出しの結果ラベル、測定後状態、対象となる記録を指定する |
| M の位相緩和・記録相関の破壊 | 対象基底と実装を固定し、読み出しを隠す操作と区別する |
| B の許されたユニタリ制御 | 結合できる部分系と制御自由度を固定する |
| 記録結果に応じた条件付き制御 | 同じ古典記録・制御予算で比較する |
| 状態の準備し直し・リセット | 補助系・初期化・廃棄先を明示できた場合だけ採用する |

これらは無条件に許される操作ではない。各候補について、制約と両立する拡大系の実装、または有効な物理的持ち上げを示す。支持空間外への漏れを射影・再正規化で隠さない。事後選択を使う場合は成功確率を含め、失敗結果も保持する。

Stage 7 の時計写像は一般に通常のユークリッド内積ではユニタリでない。正規直交化した物理座標、または誘導計量に対応する随伴・トレースで完全正値性・正規化・合成を検証する。裸の行列の共役だけで有効な instrument と断定しない。物理部分空間を保つ写像であることだけでは、事象に局在した介入の実装証明にならない。

資源予算は「アクセス可能な部分系 / 補助系の次元と初期状態 / 共同操作 / 古典記録・条件付き制御」とする。初回の事前監査で有限の予算を具体的に固定し、結果を見て変更しない。熱・エネルギー費用は今回の主張に含めない。

## 4. 新しい判定基準と検証方法

時計 X の事象 e で、装置と資源予算から独立に許容した instrument の集合を `I_X(e)`、同じ物理的操作の時計変更を `tau_{Y<-X}` とする。

**主判定対象:** 対応事象について `tau_{Y<-X}(I_X) = I_Y` が成立する条件、または包含が破れる具体例。初期・終端事象、古典結果、計量、装置の対応も含める。

`I_Y` を輸送像として定義した比較は RQ1 の整合性対照にだけ使う。RQ2 では、装置の相互作用・アクセス制約を先に定め、同じ装置の別表現と、各視点に固定した別の装置能力を区別する。「局所」のラベルを恣意的に付け直して差を作らない。

検証は三本に分ける。

1. **確率:** 対応する介入列の全結果分布を比較する。有限プローブ上の誤差と、全状態・全操作についての定理を区別する。
2. **集合・資源:** 変換後の instrument の所属を、チャネルとしての条件や代数的証明で判定する。ある Kraus 表現の非局所性や有限探索での未発見だけから、局所実装不能・最小資源を結論しない。
3. **記録:** 固定した対象変数・事前分布・予測または制御課題に対し、記録あり/なしの成功率差を測る。記録が表す相関を壊す対照と、同じ相関へのアクセスだけを隠す対照を分ける。

負の対照は、裸の操作の使い回し、誤った事象対応、誤計量、支持空間への漏れ、記録の誤対象、資源予算の不一致。数値許容誤差・入力族・操作クラス・再現コマンドは実験前に固定する。プロセステンソルは記述手段の候補であり、導入・多時点ラベルの存在から時間の創発を主張しない。

## 5. 成功条件・中止条件

**R0 の完了:** 本文の研究質問、差分候補、操作条件、判定対象、以下の継続/中止条件がレビュー可能な形で揃うこと。これは科学的成功ではない。

**後続研究の成功:** 妥当な物理的介入と RQ1 の整合性を確認したうえで、RQ2 について次のいずれかを得ること。

- 明示した操作クラス全体に対する閉性の十分条件または必要条件。
- 許容された操作が変換後のクラスに属さないことを証明した反例と、その資源上の理由。
- 初期の不一致を回復する具体的な追加資源・対応条件。最小性を主張するなら別途下限を示す。

RQ3 はその条件に記録が果たす役割を検査する。閉性が成立する結果も、反例が得られる結果も同等に受け入れる。既存定理の適用だけなら再現成果として終了し、学術的新規性を付与しない。

**中止または再設計:**

- 候補差分が既知の結果・定義上の恒等性だけで尽くされる。
- 物理的介入や内部事象対応を構成できず、外部スケジュール・制約違反・無記載の補助資源に依存する。
- 差が誤計量・型の不一致・異なる装置予算だけに由来し、それ以上の条件を特定できない。
- 装置の根拠なく局所性を定義し直す、または反例が出るまで次元・深さを増やす必要が生じる。

最後の場合も失敗理由を記録して止める。Stage 16 の探索を自動再開しない。
