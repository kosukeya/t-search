## 選ぶ一課題・理由

**処理が時間変動するとき、前回の有限記録による保証はどの条件で共通の時間平均に使え、各時点や次の試行には何を保証しないか。**

[校正監査](t_search_calibration_budget.md)の次に残ったIID・同じ処理という前提を分解する。「同分布」は緩めてもよい条件があるが、「独立」や五設定の共通の時間重みまで無断で外さない。一回で解析・有限計算を完了できる、非適応的な時間変動に限定する。ドリフトやIIDを実機認定する課題ではない。

## 固定する仮定・許容操作・変更

- 事前固定したnブロック。ブロックtの固定量子ビットインストゥルメント{Φ_t,b}は同じ五設定に共通で、ブロック間では任意に異なってよい。列は結果や現在の設定に適応せず、各使用はリセットされる。一般証明は各設定のブロック間の独立Bernoulliを要求する。同じブロック内の五使用へ同じ処理を適用できることも仮定であり、設定順のランダム化だけでは認定しない。
- 四入力0,1,＋,−の正答と、指定入力ρ・公開フラグbの出現を各ブロック一回ずつ記録し、五設定で同じ重み1/nを保つ。未検出・失敗・時間ラベルを含む生記録を選別しない。従来の任意サイズ・分離バッチから、共通のブロック対応を持つ窓口へ変更する理由は、同じ平均チャネルへ五確率を対応させるためである。
- 対象は平均インストゥルメントΦ̄_b=(1/n)Σ_tΦ_t,b。量子の部分で恒等目標・固定次元・準備測定・配線等の信頼条件を保持する。前回の決定論的な校正予算は各ブロックで共通に成り立つと仮定でき、平均へ合成する。計算対照はその予算ゼロに固定し、校正自体を認定しない。
- 前回の片側KL下限を、二項分布の母数ではなく非同分布Bernoulli列の平均確率へ適用できるか導出する。α=0.05、五母数にβ=0.01。既存のexact_probabilities認定器は呼出しも変更もしない。一般の適応的メモリ・任意停止・事後選択への拡張は含めない。
- tは試行/設定記録の古典的ラベルで、宇宙の物理時計やR5のコヒーレント履歴ではない。tを無視した平均と、tを知った条件付き予測を区別する。

## 評価・成功条件・中止条件

1. 独立・非同分布なBernoulliの指数モーメントに対する凹性からKL尾を導き、平均率の同時被覆、Hofmann下限・校正補正・分枝上限を接続する。一次資料の独立/同分布の条件を本文で確認し、既知原理の適用を新発見とは扱わない。
2. n=8,25,100、平均p=0.01,0.1,0.5,0.9,0.99で、(i)一定p、(ii)p±min(p,1−p)/2の交互列（奇数末尾はp）、(iii)総和npを1・一つの端数・0へ集中した列を固定する。計45条件のPoisson-binomial全確率を有理数DPで求め、下限が平均を超える全カウントを合計する。一定列は独立の二項式とも照合する。
3. n=25の全26³カウント判定を、位相反転フラグ対照の三列q_tで照合する。三列は一定0.1、(0,0.2)×12＋0.1、(1,1,0.5,0,…,0)。五設定間も独立の対照とし、平均q=0.1・対象分枝の真の距離1に対する偽保証確率を有理数で全和する。
4. I/Zの時刻別処理から、全良好、全位相反転、I/Z交互、誤り率(0,0.02)を粗視化、同じ誤り率で稀なZ分枝を保持、分枝重み(0.25,0.75)と作用I/Zの対照、999回I＋最後Zの七列を固定する。入力は＋、0、(I+0.2X+0.3Y+0.4Z)/2の三つ。Kraus平均と直接平均、Bell忠実度・正答率・分枝確率・条件付き状態を独立行列計算と解析式で照合し、零分枝は正規化しない。
5. 共通時間重みを破る別バッチの反例、平均誤差0.001でも最後の誤差1となる例、同じ全過去から次の処理I/Zを区別できない例を保存する。平均分枝の正規化は時間別条件付き状態の等重み平均ではないことも検算する。独立性を外す共通Bernoulli(1/2)の反例はn=100で評価する。
