# Stage 6.0 Results — Protocol Freeze

Status: **completed**.

## What was frozen

Stage 6 begins from a provisional typed container:

`T6=(O,P,R,V,Omega;Xi)`

with:

- `O`: neutral order / succession;
- `P`: perspectives and admissible perspective transformations;
- `R`: records, record-defined direction, accessibility;
- `V`: Potentiality / modality / extension semantics;
- `Omega`: operational correspondences;
- `Xi`: compatibility conditions among the layers.

This is explicitly an analysis scaffold rather than a definition of fundamental time.

## Mandatory arrow typing

Stage 6 distinguishes:

- horizontal perspective maps `M_{q<-p}`;
- vertical temporal/causal/conditioning relations `D_p(e2<-e1)` or `e1 <=_p e2`;
- explicit event-correspondence maps `chi_{q<-p}`.

The protocol forbids inferring temporal succession from perspective transformation or inferring event identity from equal numeric clock coordinates.

## Executable-evidence requirement

Stage 6A must recompute witnesses through existing Stage 1--5 model APIs where possible.

A prose conclusion copied into a boolean table does not count as evidence.

Required adapters are frozen for:

- Stage 1 reconstruction versus accessibility;
- Stage 2 modal distinction versus operational equality;
- Stage 3 order / record-orientation controls;
- Stage 4 same-clock transition composition;
- Stage 5 genuine cross-clock composition plus operational/perspective-dependent structure.

## Independence statuses

The only allowed implication statuses are:

- `refuted`;
- `supported_in_declared_family`;
- `not_established`.

`not_established` is not treated as false.

The frozen implication matrix contains at least ten candidate implications, including `order => arrow`, `operational equality => modal equivalence`, `reconstructibility => accessibility`, and `perspective consistency => temporal arrow`.

## Partial-atlas protocol

Stage 6C must remove primitive direct perspective edges, reconstruct indirect maps where paths exist, compare alternate paths, test closed-loop consistency, distinguish missing direct edges from missing perspectives, and detect deliberate edge perturbations.

A nonzero algebraic loop residual is not interpreted as spacetime curvature without an independent physical derivation.

## Compatibility protocol

Stage 6D must contain both typed horizontal and vertical arrows and an explicit event correspondence.

Candidate commuting squares compare:

`perspective transport then temporal relation`

with:

`temporal relation then perspective transport`.

A successful square is compatibility evidence, not evidence that the two arrow types are the same structure.

## Record / modality transport

Stage 6E must:

- declare whether an event correspondence preserves or reverses modeled orientation before comparing record signs;
- retain accessibility as distinct from global record existence;
- define an explicit relation between modal extension sets before testing it;
- preserve Stage 2 operational/modal underdetermination unless a genuinely discriminating witness breaks it.

## Minimality / ablation

Stage 6F must remove or neutralize candidate layers and classify affected temporal roles as preserved, reconstructible, inaccessible, lost, not-applicable, or not-established.

A software dependency alone cannot establish metaphysical fundamentality.
