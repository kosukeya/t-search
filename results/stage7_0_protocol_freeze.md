# Stage 7.0 Results — Protocol Freeze

Status: **completed on the Stage 7 protocol branch**.

## Why Stage 7 changed from the older roadmap

An earlier roadmap version assigned Stage 7 to a generally covariant / gravitational extension.

Stage 6G supplied a more discriminating evidence-based gate before that jump:

**put explicit memory/record structure and genuine multi-clock perspective change into one constrained quantum construction.**

The roadmap is therefore revised so that gravitational/general-covariant work is deferred rather than discarded.

## Central Stage 7 question

> In one constrained finite quantum model containing multiple admissible internal clock perspectives and an explicit memory degree of freedom, does record-defined temporal structure remain distinct from perspective transformation and neutral order while transforming consistently under genuine clock changes?

This directly pressure-tests the Stage 6 candidate:

`T6_candidate=(O,P,R,V;Xi)`.

Stage 7 focuses first on `P/O/R`; explicit `V` integration is reserved as a later evidence-selected gate.

## Minimal baseline

The least-invasive control extends the Stage 5 carrier with a memory qubit:

`H_kin^7=H_A tensor H_B tensor H_C tensor H_M`

with:

`H_M=C^2`, `H_M^(0)=0`.

For the spectator-memory baseline only:

`H_phys^(0)=H_phys^(5) tensor H_M`

and the inherited reductions/clock-change maps are expected to tensor with `I_M`.

This baseline is explicitly **not** counted as record formation.

## Record semantics frozen

A quantum record requires:

- an explicit target observable/variable;
- an explicit memory readout;
- target-specific record information;
- no-record/wrong-target controls;
- explicit event/history correspondence before any past/future/orientation language is used.

Frozen distinctions include:

- `memory present != record present`;
- `entanglement != record`;
- `record correlation != record-defined orientation`;
- `physical-subspace automorphism != time-localized interaction`;
- `simulation/intervention order != modeled temporal order`.

## Physical admissibility rule

A support-local unitary cannot be called an autonomous physical record-forming interaction merely because its matrix is unitary.

If a relationally localized interaction modifies the constraint,

`H_tot^(rec)=H_tot^(0)+H_int`,

then the physical subspace, reductions, supports, and perspective maps must be recomputed. The Stage 5 formulas may not be reused unchanged by assumption.

This rule deliberately allows Stage 7 to discover an incompatibility between record-forming interactions and the inherited ideal clock atlas.

## Required controls

The protocol requires, when applicable:

- no record coupling;
- maximally uncertain/mixed memory;
- wrong target;
- untransported bare observable;
- wrong `chi`;
- reversed/inverse history construction;
- balanced forward/reverse orientation;
- hidden/noisy memory access;
- perturbed perspective path;
- rejection of constraint-invalid candidates.

## Exit discipline

Stage 7 has **36 exit criteria** covering typing, spectator-memory baseline, record witness, reversal controls, genuine clock-change transport, accessibility/partial-atlas consistency, minimality, synthesis, and final regression/merge-readiness.

## Strongest allowed Stage 7.0 statement

**Stage 6 justifies testing `P`, `O`, and `R` inside one constrained finite quantum construction. An explicit memory subsystem and reversible record-writing operation can be specified as candidate ingredients, but Stage 7.0 does not yet establish that directional records can be physically formed inside the multi-clock constrained model, that such records transform covariantly under genuine clock changes, or that the Stage 6 layered temporal candidate survives this stronger single-model test.**
